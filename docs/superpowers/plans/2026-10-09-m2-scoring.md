# Coglossa M2 — Scoring: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace M1's null scores with real per-span scoring (spec §6). Each span gets:
- **Signals:** `qe`, `xsim`, `roundtrip`, `judge`, `agreement` and `bible_check`
- **Scores:** `meaning` and `style`, each 0–100
- **Reliability:** a tier (A/B/C) with downgrades
- **Flags:** threshold flags and hard triggers

The model-based signals come from a new self-hosted **scorer service** (MetricX-24 + LaBSE). An LLM **judge** and **roundtrip** back-translation run against the customer's own OpenAI-compatible servers, as in M1.

**Architecture:**
- The engine (`engine/`) stays lightweight. It talks to the scorer over HTTP through a `Scorer` protocol, and judge and roundtrip are two new agent stages on the existing `AgentRunner`.
- Aggregation is a pure function from evidence to scores and flags, so it is property-testable.
- The scorer (`scorer/`) is a separate Python package and service: FastAPI plus torch/transformers/sentence-transformers. It loads models from local directories only, so it works air-gapped.
- The JSON contract between engine and scorer is exported from engine Pydantic models into `schema/`, and the scorer's tests validate their responses against those files.

**Tech Stack:**
- Engine: unchanged from M1 (Python ≥3.12, uv, Pydantic v2, httpx, pytest + Hypothesis, ruff).
- Scorer: FastAPI, uvicorn, torch (CPU wheels on Linux CI), transformers ≥4.44, sentencepiece, sentence-transformers ≥3, numpy, jsonschema for the contract tests.

**Spec:** `docs/superpowers/specs/2026-10-09-coglossa-v1-design.md`, §6 (scoring), §3 (configuration) and §11 (milestone M2). M1 code is on `main`; read `engine/coglossa/pipeline.py`, `stages/score.py` and `prompts/check.py` before Tasks 7–9.

## Global Constraints

- Every M1 constraint still holds:
  - Python `>=3.12`; uv only.
  - 95% branch coverage per package (`--cov-branch --cov-fail-under=95`).
  - `pytest -W error` must be clean, and `make lint` and `make schema` must show no drift.
  - Tests never touch the network except `127.0.0.1`.
  - Every model call is logged.
  - **Scores are never invented** (spec §1.2): a signal that can't be computed is `null`.
- The engine package **must not import torch, transformers, sentence-transformers or numpy**. Model-based signals reach the engine only over HTTP from the scorer service.
- **The scorer loads models only from local paths** given on its command line. It sets `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1` before importing transformers. No test downloads weights: tests use a tiny randomly initialised mT5 and fake tokenizers and encoders. Real-model tests are opt-in (`COGLOSSA_REAL_MODELS=1`) and excluded from CI.
- **MetricX-24 facts** (from `google-research/metricx`, Apache-2.0):
  - QE input is `"source: {src} candidate: {hyp}"`. Reference mode is `"source: {src} candidate: {hyp} reference: {ref}"`.
  - Tokenizer `google/mt5-xl`, `max_input_length` 1536. Tokenize without padding, **drop the final EOS token** of each example, then pad.
  - Decoder input is a single token id `0`. The prediction is `lm_logits[:, 0, 250089]` clamped to `[0, 25]`, and lower is better.
  - We load checkpoints with stock `transformers.MT5ForConditionalGeneration`. It has the same parameters and forward computation as MetricX's `MT5ForRegression`, so nothing is vendored.
- **LaBSE:** `sentence-transformers/LaBSE` (Apache-2.0), with normalised embeddings. Similarity is the dot product of normalised vectors, in `[-1, 1]`.
- **Normalisation, used everywhere:**
  - `qe_norm = clamp(1 - raw/25, 0, 1)`
  - `sim_norm = clamp((cos - xsim_floor) / (1 - xsim_floor), 0, 1)`, with default `xsim_floor` 0.5
  - `judge_acc = clamp(1 - accuracy_penalty / judge_penalty_scale, 0, 1)` and the same for style, with default scale 10
  - MQM penalties default to minor 1, major 5, critical 10
- **Meaning:** `meaning = 100 × weighted mean of the available normalised {qe, xsim, roundtrip, judge_acc, agreement}`, renormalised over the signals that are present. `style = 100 × judge_style`. `meaning` is `null` unless at least one model signal (qe, xsim, roundtrip, judge) is present. Agreement only refines it and never stands alone. `style` is `null` without the judge.
- **Default weights** (tier → qe/xsim/roundtrip/judge/agreement):
  - A: .35/.10/.20/.30/.05
  - B: .30/.10/.20/.30/.10
  - C: .10/.05/.30/.40/.15
  - The roundtrip weight is multiplied by `literary_roundtrip_factor` (0.5) when the genre is `literary_prose` or `poetry`.
- **Default thresholds:** meaning A 70 / B 72 / C 75; style 60. Length-ratio band (target chars / source chars) is `[0.5, 2.0]`.
- **Reliability** starts at the language-pair tier from `tiers.yaml`, the worse of the two languages unless an explicit pair entry exists. It drops one step (A→B→C, C stays C) when two or more of {qe, xsim, roundtrip, judge} are `null`, or when the run lacks model diversity (judge missing or equal to the reviewer's model, or roundtrip missing or shared with a translator). Spans with empty text are `unscored`.
- **Hard triggers** (spec §6.3) flag regardless of scores:
  - a critical judge error (accuracy → `low_meaning`, style → `style_drift`)
  - a locked-term violation (`terminology_violation`)
  - reviewer agreement `major` (`agent_disagreement`, unchanged from M1)
  - a length ratio outside the band **and** a judge omission error (`possible_omission`)
- **Tier C** documents carry a document-level `low_reliability_language` notice: "Scores for {src}→{tgt} are less reliable — review more broadly."
- Scorer, judge and roundtrip failures **never fail a run**. The affected signals are `null`, a `RunError` is recorded (stage `score`, `judge` or `roundtrip`), and the run continues.
- Default tiers are **provisional** until `coglossa bench` (M6) calibrates them. Say so in `tiers.yaml` and the README.

## Review Focus

These are inputs the spec implies but doesn't directly exercise. Each gets a test in the task named.

1. **The scorer is down, slow, or returns the wrong number of scores.** The run must finish with those signals `null`, reliability downgraded, one `RunError` per chunk, and a clear stderr warning at startup (Tasks 3, 8, 9).
2. **A span whose final text is empty** (an `engine_error` fallback with no candidates) must not be sent to the scorer or judge, and must be `unscored` rather than scored as 0 (Task 8).
3. **A judge that cites an excerpt not in the translation, or returns span ranges that don't match**, triggers the repair retry. After that the judge signal is `null` for the chunk, never misattributed (Task 5).
4. **Unknown or odd language codes** (`und`, `pt-BR`, `zh-Hant`, uppercase) map to a sensible tier: the base subtag, case-insensitive, with unknown codes falling to the default tier C (Task 2).
5. **Batches longer than the scorer's maximum**, and very long inputs (MetricX truncates at 1536 tokens), must be split client-side and stay order-aligned. On the scorer side the result must not depend on batch composition, which checks the padding and attention mask (Tasks 3, 10).

## Deferred to Later Milestones (do not build in M2)
- Using judge or roundtrip results to *revise* translations: that's the sweep, in M3.
- Calibrating weights and tiers from data: `coglossa bench` in M6.
- Scorer Dockerfile, bundling weights, GPU deployment docs: M5.
- UI rendering of judge error highlights: M4.

```python
    hypothesis: str

class QEResponse(BaseModel):
    scores: list[float] = Field(

    )


class SimilarityPair(BaseModel):
    a: str
    b: str


class SimilarityRequest(BaseModel):
    pairs: list[SimilarityPair] = Field(min_length=1, max_length=SCORER_MAX_BATCH)


class SimilarityResponse(BaseModel):
    similarities: list[float] = Field(
        description="Cosine similarity in [-1, 1], one per pair, in order"
    )


class ScorerHealth(BaseModel):
    status: Literal["ok"] = "ok"
    qe_model: str | None = None
    embed_model: str | None = None
    device: str
```

```python
"""Language-pair reliability tiers (spec §6.4)."""

from pathlib import Path
from typing import Any

import yaml

from coglossa.config import ConfigError
from coglossa.schema import Reliability

DEFAULT_TIERS_FILE = Path(__file__).with_name("tiers.yaml")
_BY_NAME = {"A": Reliability.A, "B": Reliability.B, "C": Reliability.C}
_RANK = {Reliability.A: 0, Reliability.B: 1, Reliability.C: 2}
_NEXT = {Reliability.A: Reliability.B, Reliability.B: Reliability.C}


def base_language(code: str) -> str:
    return code.strip().replace("_", "-").split("-")[0].lower()


def downgrade(tier: Reliability) -> Reliability:
    return _NEXT.get(tier, tier)


class LanguageTiers:
    def __init__(
        self,
        languages: dict[str, Reliability],
        pairs: dict[tuple[str, str], Reliability],
        default: Reliability,
    ) -> None:
        self.languages = languages
        self.pairs = pairs
        self.default = default

    @classmethod
    def load(cls, path: Path | None = None) -> "LanguageTiers":
        path = path or DEFAULT_TIERS_FILE
        try:
            raw: Any = yaml.safe_load(path.read_text(encoding="utf-8")) or {}
        except (OSError, UnicodeDecodeError, yaml.YAMLError) as e:
            raise ConfigError(f"cannot read language tiers file {path}: {e}") from e
        if not isinstance(raw, dict):
            raise ConfigError(f"{path}: expected a mapping")

        def tier_of(value: object, where: str) -> Reliability:
            if value not in _BY_NAME:
                raise ConfigError(f"{path}: {where}: tier must be A, B or C, got {value!r}")
            return _BY_NAME[str(value)]

        default = tier_of(raw.get("default", "C"), "default")
        languages: dict[str, Reliability] = {}
        for tier_name, codes in (raw.get("languages") or {}).items():
            tier = tier_of(tier_name, "languages")
            if not isinstance(codes, list):
                raise ConfigError(f"{path}: languages.{tier_name} must be a list")
            for code in codes:
                languages[base_language(str(code))] = tier
        pairs: dict[tuple[str, str], Reliability] = {}
        for key, value in (raw.get("pairs") or {}).items():
            src, sep, tgt = str(key).partition(">")
            if not sep or not src.strip() or not tgt.strip():
                raise ConfigError(f"{path}: pairs key {key!r} must look like 'src>tgt'")
            pairs[(base_language(src), base_language(tgt))] = tier_of(value, f"pairs.{key}")
        return cls(languages, pairs, default)

    def tier(self, source_lang: str, target_lang: str) -> Reliability:
        src, tgt = base_language(source_lang), base_language(target_lang)
        if (src, tgt) in self.pairs:
            return self.pairs[(src, tgt)]
        tiers = (self.languages.get(src, self.default), self.languages.get(tgt, self.default))
        return max(tiers, key=_RANK.__getitem__)
```

```python
"""Engine side of the scorer service (spec §6.1): a small HTTP client behind a protocol.
Third parties can add scorer kinds (e.g. a licensed CometKiwi) via `coglossa.scorers`."""

from collections.abc import Callable
from importlib.metadata import entry_points
from typing import Any, Protocol, TypeVar

import httpx
from pydantic import BaseModel, ValidationError

from coglossa.config import CoglossaConfig, ConfigError, ScorerConfig
from coglossa.schema import (
    QEItem,
    QERequest,
    QEResponse,
    ScorerHealth,
    SimilarityPair,
    SimilarityRequest,
    SimilarityResponse,
)

M = TypeVar("M", bound=BaseModel)


class ScorerUnavailableError(Exception):
    """The scorer could not produce scores; the affected signals become null."""


class Scorer(Protocol):
    name: str

    async def qe(self, items: list[QEItem]) -> list[float]: ...

    async def similarity(self, pairs: list[SimilarityPair]) -> list[float]: ...

    async def health(self) -> ScorerHealth: ...

    async def aclose(self) -> None: ...


class HttpScorer:
    def __init__(
        self,
        url: str,
        *,
        timeout_s: float = 300.0,
        max_batch: int = 64,
        transport: httpx.AsyncBaseTransport | None = None,
    ) -> None:
        self.name = "http"
        self._client = httpx.AsyncClient(
            base_url=url.rstrip("/") + "/", timeout=timeout_s, transport=transport
        )
        self._max_batch = max_batch

    async def qe(self, items: list[QEItem]) -> list[float]:
        scores: list[float] = []
        for start in range(0, len(items), self._max_batch):
            batch = items[start : start + self._max_batch]
            data = await self._request("POST", "v1/qe", json=QERequest(items=batch).model_dump())
            got = _parse(QEResponse, data).scores
            if len(got) != len(batch):
                raise ScorerUnavailableError(
                    f"scorer returned {len(got)} scores for {len(batch)} items"
                )
            scores.extend(got)
        return scores

    async def similarity(self, pairs: list[SimilarityPair]) -> list[float]:
        sims: list[float] = []
        for start in range(0, len(pairs), self._max_batch):
            batch = pairs[start : start + self._max_batch]
            body = SimilarityRequest(pairs=batch).model_dump()
            got = _parse(SimilarityResponse, await self._request("POST", "v1/similarity", json=body))
            if len(got.similarities) != len(batch):
                raise ScorerUnavailableError(
                    f"scorer returned {len(got.similarities)} similarities for {len(batch)} pairs"
                )
            sims.extend(got.similarities)
        return sims

    async def health(self) -> ScorerHealth:
        return _parse(ScorerHealth, await self._request("GET", "health"))

    async def aclose(self) -> None:
        await self._client.aclose()

    async def _request(self, method: str, path: str, **kwargs: Any) -> Any:
        try:
            resp = await self._client.request(method, path, **kwargs)
        except httpx.HTTPError as e:
            raise ScorerUnavailableError(f"scorer unreachable: {type(e).__name__}: {e}") from e
        if resp.status_code >= 400:
            raise ScorerUnavailableError(f"scorer HTTP {resp.status_code}: {resp.text[:300]}")
        try:
            return resp.json()
        except ValueError as e:
            raise ScorerUnavailableError("scorer returned invalid JSON") from e


def _parse(model: type[M], data: Any) -> M:
    try:
        return model.model_validate(data)
    except ValidationError as e:
        raise ScorerUnavailableError(f"scorer sent an unexpected response: {e}") from e


ScorerFactory = Callable[[ScorerConfig], Scorer]


def build_scorer(cfg: CoglossaConfig) -> Scorer | None:
    sc = cfg.scorer
    if sc is None or sc.kind == "none":
        return None
    if sc.kind == "http":
        return HttpScorer(sc.url or "", timeout_s=sc.timeout_s, max_batch=sc.max_batch)
    plugins = {ep.name: ep for ep in entry_points(group="coglossa.scorers")}
    if sc.kind not in plugins:
        available = ", ".join(["http", "none", *sorted(plugins)])
        raise ConfigError(f"scorer: unknown kind '{sc.kind}' (available: {available})")
    factory: ScorerFactory = plugins[sc.kind].load()
    return factory(sc)
```

```python
        return

        self.server.requests.append({"path": self.path})
        if self.path.rstrip("/") == "/health":
            self._send(200, FAKE_HEALTH.model_dump())
        else:
            self._send(404, {"detail": "not found"})

    def do_POST(self) -> None:
        self.server.requests.append({"path": self.path})
        raw = self.rfile.read(int(self.headers.get("Content-Length", "0")))
        if self.path not in ("/v1/qe", "/v1/similarity"):
            self._send(404, {"detail": "not found"})
            return
        if self.server.fail_status is not None:
            self._send(self.server.fail_status, {"detail": "configured failure"})
            return
        try:
            body = json.loads(raw)
            if self.path == "/v1/qe":
                req = QERequest.model_validate(body)
                self._send(200, {"scores": [fake_qe(i, {}) for i in req.items]})
            else:
                sreq = SimilarityRequest.model_validate(body)
                self._send(200, {"similarities": [fake_similarity(p) for p in sreq.pairs]})
        except (ValueError, ValidationError) as e:
            self._send(422, {"detail": str(e)})

        data = json.dumps(obj).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

            self._thread.join()
```

```python
"""Rule-based scoring signals (spec §6.1): reviewer agreement, bible consistency, length
ratio, and MQM-style judge penalties. Pure functions; no I/O."""

from dataclasses import asdict, dataclass
from typing import Literal

from coglossa.schema import ACCURACY_CATEGORIES, Agreement, Bible, ErrorSeverity, JudgeError

_AGREEMENT_VALUE = {Agreement.AGREE: 1.0, Agreement.MINOR: 0.7, Agreement.MAJOR: 0.2}


def agreement_signal(agreement: Agreement, candidate_similarity: float | None) -> float | None:
    parts = [p for p in (_AGREEMENT_VALUE.get(agreement), candidate_similarity) if p is not None]
    return sum(parts) / len(parts) if parts else None


@dataclass(frozen=True)
class BibleViolation:
    term: str
    expected: str
    kind: Literal["glossary", "entity"]
    locked: bool

    def as_evidence(self) -> dict[str, object]:
        return asdict(self)


def bible_check(
    source_text: str, final_text: str, bible: Bible
) -> tuple[float | None, list[BibleViolation]]:
    src, out = source_text.casefold(), final_text.casefold()
    applicable = 0
    violations: list[BibleViolation] = []
    for g in bible.glossary:
        if g.term.casefold() in src:
            applicable += 1
            if g.rendering.casefold() not in out:
                violations.append(BibleViolation(g.term, g.rendering, "glossary", g.locked))
    for e in bible.entities:
        if e.name.casefold() in src:
            applicable += 1
            if e.rendering.casefold() not in out:
                violations.append(BibleViolation(e.name, e.rendering, "entity", False))
    if applicable == 0:
        return None, []
    return (applicable - len(violations)) / applicable, violations


def length_ratio(source_text: str, final_text: str) -> float | None:
    src = len(source_text.strip())
    return len(final_text.strip()) / src if src else None


def judge_penalties(
    errors: list[JudgeError], penalties: dict[ErrorSeverity, float]
) -> tuple[float, float]:
    accuracy = sum(penalties[e.severity] for e in errors if e.category in ACCURACY_CATEGORIES)
    style = sum(penalties[e.severity] for e in errors if e.category not in ACCURACY_CATEGORIES)
    return accuracy, style
```

```python
def check_judgements(out: JudgeOutput, spans: list[ReconciledSpan]) -> list[str]:
    expected = [(s.start, s.end) for s in spans]
    got = [(j.start, j.end) for j in out.spans]
    if got != expected:
        want = ", ".join(f"{a}..{b}" for a, b in expected)
        return [f"spans must be exactly [{want}] in order; got {len(got)} spans: {got}"]
    texts = {(s.start, s.end): s.text for s in spans}
    problems: list[str] = []
    for k, judgement in enumerate(out.spans):
        text = texts[(judgement.start, judgement.end)]
        for m, err in enumerate(judgement.errors):
            where = f"spans[{k}].errors[{m}]"
            if err.category is not ErrorCategory.OMISSION and not err.excerpt.strip():
                problems.append(f"{where}: excerpt is required for {err.category.value}")
            elif err.excerpt and err.excerpt not in text:
                problems.append(
                    f"{where}: excerpt {err.excerpt!r} does not appear in the span's translation"
                )
    return problems


@dataclass
class JudgeResult:
    errors_by_span: list[list[JudgeError]] | None
    run_errors: list[RunError]


async def judge_chunk(

    if role is None:
        return JudgeResult(None, [])
    judged = [s for s in spans if s.text.strip()]
    if not judged:
        return JudgeResult([[] for _ in spans], [])
    sliced = bible_slice(bible, "\n".join(s.text for s in ci.segments))
    try:
        out = await ctx.runner.run(
            role="judge",
            model_key=role.model,
            prompt_id="judge",
            prompt_vars={"source_lang": profile.source_lang, "target_lang": profile.target_lang},
            payload={
                "task": "judge",
                "source_lang": profile.source_lang,
                "target_lang": profile.target_lang,
                "bible": sliced.model_dump(),
                "segments": [{"id": s.id, "text": s.text} for s in ci.segments],
                "spans": [{"start": s.start, "end": s.end, "text": s.text} for s in judged],
            },
            output_type=JudgeOutput,
            validate=lambda o: check_judgements(o, judged),
        )
    except AGENT_FAILURES as e:
        return JudgeResult(
            None, [RunError(stage="judge", chunk_id=ci.chunk.id, role="judge", message=str(e))]
```

```python
"""Roundtrip stage (spec §6.1): back-translate final spans into the source language."""

from dataclasses import dataclass

from coglossa.llm.agent import AGENT_FAILURES
from coglossa.schema import DocumentProfile, ReconciledSpan, RunError, TranslationOutput
from coglossa.stages.context import StageContext
from coglossa.stages.translate import ChunkInput


def check_backtranslation(out: TranslationOutput, spans: list[ReconciledSpan]) -> list[str]:
    expected = [(s.start, s.end) for s in spans]
    got = [(t.start, t.end) for t in out.spans]
    if got != expected:
        want = ", ".join(f"{a}..{b}" for a, b in expected)
        return [f"spans must be exactly [{want}] in order; got {len(got)} spans: {got}"]
    return []


@dataclass
class RoundtripResult:
    texts: list[str | None] | None
    run_errors: list[RunError]


async def back_translate_chunk(
    ctx: StageContext, profile: DocumentProfile, ci: ChunkInput, spans: list[ReconciledSpan]
) -> RoundtripResult:
    role = ctx.cfg.roles.roundtrip
    if role is None:
        return RoundtripResult(None, [])
    sent = [s for s in spans if s.text.strip()]
    if not sent:
        return RoundtripResult([None for _ in spans], [])
    try:
        out = await ctx.runner.run(
            role="roundtrip",
            model_key=role.model,
            prompt_id="back_translate",
            prompt_vars={"from_lang": profile.target_lang, "to_lang": profile.source_lang},
            payload={
                "task": "back_translate",
                "from_lang": profile.target_lang,
                "to_lang": profile.source_lang,
                "spans": [{"start": s.start, "end": s.end, "text": s.text} for s in sent],
            },
            output_type=TranslationOutput,
            validate=lambda o: check_backtranslation(o, sent),
        )
    except AGENT_FAILURES as e:
        return RoundtripResult(
            None,
            [RunError(stage="roundtrip", chunk_id=ci.chunk.id, role="roundtrip", message=str(e))],
        )
    by_range = {(t.start, t.end): t.text for t in out.spans}
    return RoundtripResult([by_range.get((s.start, s.end)) for s in spans], [])
```

```python
Pure functions: the pipeline gathers evidence; this module decides."""

from dataclasses import dataclass

from coglossa.config import CoglossaConfig, ScoringConfig, SignalWeights
from coglossa.schema import (
    ACCURACY_CATEGORIES,
    ErrorCategory,
    ErrorSeverity,
    Flag,
    FlagCode,
    Genre,
    JudgeError,
    Reliability,
    SpanScore,
)
from coglossa.scoring.rules import BibleViolation, judge_penalties
from coglossa.scoring.tiers import downgrade

SIGNALS = ("qe", "xsim", "roundtrip", "judge", "agreement", "bible_check")
MODEL_SIGNALS = ("qe", "xsim", "roundtrip", "judge")
LITERARY = frozenset({Genre.LITERARY_PROSE, Genre.POETRY})


@dataclass(frozen=True)
class SpanEvidence:
    source_text: str
    final_text: str
    genre: Genre
    qe_raw: float | None = None
    xsim_cos: float | None = None
    roundtrip_qe_raw: float | None = None
    roundtrip_cos: float | None = None
    judge_errors: list[JudgeError] | None = None  # None = judge unavailable
    agreement: float | None = None
    bible_signal: float | None = None
    bible_violations: tuple[BibleViolation, ...] = ()
    length_ratio: float | None = None


def _clamp01(x: float) -> float:
    return max(0.0, min(1.0, x))


def normalize_qe(raw: float | None) -> float | None:
    return None if raw is None else _clamp01(1 - raw / 25)


def normalize_sim(cos: float | None, floor: float) -> float | None:
    return None if cos is None else _clamp01((cos - floor) / (1 - floor))


def _mean(values: list[float | None]) -> float | None:
    present = [v for v in values if v is not None]
    return sum(present) / len(present) if present else None


def _weighted_meaning(
    signals: dict[str, float | None], weights: SignalWeights, roundtrip_factor: float
) -> float | None:
    pairs = [
        (signals["qe"], weights.qe),
        (signals["xsim"], weights.xsim),
        (signals["roundtrip"], weights.roundtrip * roundtrip_factor),
        (signals["judge"], weights.judge),
        (signals["agreement"], weights.agreement),
    ]
    available = [(v, w) for v, w in pairs if v is not None and w > 0]
    total = sum(w for _, w in available)
    if total == 0:
        return None
    return 100 * sum(v * w for v, w in available) / total


def score_span(
    ev: SpanEvidence, *, tier: Reliability, cfg: ScoringConfig, diverse: bool
) -> tuple[SpanScore, list[Flag]]:
    if not ev.final_text.strip():
        return SpanScore(signals=dict.fromkeys(SIGNALS)), []
    judge_acc = judge_style = None
    if ev.judge_errors is not None:
        acc_pen, sty_pen = judge_penalties(ev.judge_errors, cfg.mqm_penalties)
        judge_acc = _clamp01(1 - acc_pen / cfg.judge_penalty_scale)
        judge_style = _clamp01(1 - sty_pen / cfg.judge_penalty_scale)
    signals: dict[str, float | None] = {
        "qe": normalize_qe(ev.qe_raw),
        "xsim": normalize_sim(ev.xsim_cos, cfg.xsim_floor),
        "roundtrip": _mean(
            [normalize_qe(ev.roundtrip_qe_raw), normalize_sim(ev.roundtrip_cos, cfg.xsim_floor)]
        ),
        "judge": judge_acc,
        "agreement": ev.agreement,
        "bible_check": ev.bible_signal,
    }
    factor = cfg.literary_roundtrip_factor if ev.genre in LITERARY else 1.0
    has_model_signal = any(signals[name] is not None for name in MODEL_SIGNALS)
    meaning = (
        _weighted_meaning(signals, cfg.weights_by_tier[tier.value], factor)
        if has_model_signal
        else None
    )
    style = None if judge_style is None else 100 * judge_style
    missing = sum(signals[name] is None for name in MODEL_SIGNALS)
    reliability = downgrade(tier) if missing >= 2 or not diverse else tier
    score = SpanScore(
        signals=signals,
        meaning=None if meaning is None else round(meaning, 1),
        style=None if style is None else round(style, 1),
        reliability=reliability,
    )
    return score, _flags(ev, score, tier, cfg)


def _flags(ev: SpanEvidence, score: SpanScore, tier: Reliability, cfg: ScoringConfig) -> list[Flag]:
    errors = ev.judge_errors or []
    accuracy = [e for e in errors if e.category in ACCURACY_CATEGORIES]
    style = [e for e in errors if e.category not in ACCURACY_CATEGORIES]
    base = {"signals": score.signals, "meaning": score.meaning, "style": score.style}
    flags: list[Flag] = []

    threshold = cfg.thresholds.meaning[tier.value]
    flag = _threshold_flag(
        FlagCode.LOW_MEANING, "Meaning", score.meaning, threshold, accuracy, base
    )
    if flag:
        flags.append(flag)
    flag = _threshold_flag(
        FlagCode.STYLE_DRIFT, "Style", score.style, cfg.thresholds.style, style, base
    )
    if flag:
        flags.append(flag)

    locked = [v for v in ev.bible_violations if v.locked]
    if locked:
        rules = "; ".join(f"'{v.term}' should be rendered as '{v.expected}'" for v in locked)
        flags.append(Flag(
            code=FlagCode.TERMINOLOGY_VIOLATION,
            explanation=f"Locked glossary terms were not followed: {rules}.",
            evidence={"violations": [v.as_evidence() for v in locked]},
        ))

    omissions = [e for e in accuracy if e.category is ErrorCategory.OMISSION]
    low, high = cfg.length_ratio_band
    ratio = ev.length_ratio
    if omissions and ratio is not None and not low <= ratio <= high:
        flags.append(Flag(
            code=FlagCode.POSSIBLE_OMISSION,
            explanation=(
                f"The translation is {ratio:.2f}× the length of the source and the judge "
                f"reported an omission: {omissions[0].explanation}"
            ),
            evidence={"length_ratio": ratio, "band": [low, high],
                      "judge_errors": [e.model_dump() for e in omissions]},
        ))
    return flags


def _threshold_flag(
    code: FlagCode,
    label: str,
    value: float | None,
    threshold: float,
    errors: list[JudgeError],
    base: dict[str, object],
) -> Flag | None:
    critical = [e for e in errors if e.severity is ErrorSeverity.CRITICAL]
    below = value is not None and value < threshold
    if not below and not critical:
        return None
    if below:
        head = f"{label} score {value:.0f} is below the {threshold:.0f} threshold."
    else:
        head = f"A critical {label.lower()} error was found."
    reason = (critical or errors)[0].explanation if (critical or errors) else None
    tail = f" {reason}" if reason else " Compare the translation with the source carefully."
    return Flag(
        code=code,
        explanation=head + tail,
        evidence={**base, "threshold": threshold,
                  "judge_errors": [e.model_dump() for e in errors]},
    )


def model_diversity(cfg: CoglossaConfig) -> bool:
    roles = cfg.roles
    translator_models = {t.model for t in roles.translators()}
    judge_ok = roles.judge is not None and roles.judge.model != roles.reviewer.model
    roundtrip_ok = roles.roundtrip is not None and roles.roundtrip.model not in translator_models
    return judge_ok and roundtrip_ok


def document_notices(tier: Reliability, source_lang: str, target_lang: str) -> list[Flag]:
    if tier is not Reliability.C:
        return []
    return [Flag(
        code=FlagCode.LOW_RELIABILITY_LANGUAGE,
        explanation=(
            f"Scores for {source_lang}→{target_lang} are less reliable — review more broadly."
        ),
        evidence={"tier": tier.value},
    )]
```

  - `LanguageTiers` (Task 2)
  - the M1 `ReconcileResult`, `ChunkInput` and `competing_candidates`
- Produces:
  - `coglossa.stages.score.ChunkScores(scores: list[SpanScore], flags: list[list[Flag]], judge_errors: list[list[JudgeError]], back_translations: list[str | None], run_errors: list[RunError])`, aligned with `reconciled.spans`

- **`score_chunk` flow:**
  1. Live spans are those with non-blank text.
  2. In parallel, run four things:
     - `judge_chunk`
     - `back_translate_chunk`
     - scorer QE on `(source, final)` for live spans
     - scorer similarity on `(source, final)` for live spans, plus candidate pairs. For each live span, join the overlapping candidates' texts per translator, then take every unordered pair of translators' joined texts.
  3. After the back-translation, make one more scorer round:
     - QE in reference mode: `QEItem(source="", hypothesis=bt, reference=source)`
     - similarity on `(source, bt)`
  4. Build a `SpanEvidence` for each span and call `score_span`.
  - `candidate_similarity` is `normalize_sim(mean cosine of the span's candidate pairs, cfg.scoring.xsim_floor)`, or `None` when a span has fewer than two translators.
  - Any number of scorer failures in a chunk produce exactly **one** `RunError(stage="score", chunk_id, role="scorer", message)`. The failed call's signals are `None`, while other calls' results are kept.
  - With `scorer=None`, no scorer calls are made and no error is recorded.
- **Pipeline changes:**
  - Load `LanguageTiers.load(cfg.scoring.language_tiers_file)` right after `validate_prompts`, so a bad tiers file is a `ConfigError` before any model call.
  - After the profile, `tier = tiers.tier(profile.source_lang, profile.target_lang)`.
  - `diverse = model_diversity(cfg)`.
  - Each chunk runs translate, then reconcile, then `score_chunk`.
  - Span flags are `initial_flags(...)` followed by the aggregate flags.
  - `Span.score`, `judge_errors` and `back_translation` are filled in.
  - `Report.language_tier = tier` and `Report.notices = document_notices(...)`.
  - `prompt_versions` also lists `judge` and `back_translate` when those roles are set.
  - After the report is assembled, emit a progress line `scoring: tier {T}, {k} of {n} spans flagged`, where *flagged* means the span has any flag.

```python
class ChunkScores:

    run_errors: list[RunError]


def span_source_text(ci: ChunkInput, start: str, end: str) -> str:
    ids = [s.id for s in ci.segments]
    a, b = ids.index(start), ids.index(end)
    return " ".join(s.text for s in ci.segments[a : b + 1])


class _ScorerCalls:
    """Wraps the optional scorer; remembers the first failure, returns None for failed calls."""

    def __init__(self, scorer: Scorer | None) -> None:
        self.scorer = scorer
        self.error: str | None = None

    async def qe(self, items: list[QEItem]) -> list[float] | None:
        if self.scorer is None:
            return None
        try:
            return await self.scorer.qe(items)
        except ScorerUnavailableError as e:
            self.error = self.error or str(e)
            return None

    async def similarity(self, pairs: list[SimilarityPair]) -> list[float] | None:
        if self.scorer is None:
            return None
        try:
            return await self.scorer.similarity(pairs)
        except ScorerUnavailableError as e:
            self.error = self.error or str(e)
            return None


def _candidate_pairs(
    ci: ChunkInput, candidates: list[Candidate], start: str, end: str
) -> list[SimilarityPair]:
    positions = {s.id: k for k, s in enumerate(ci.segments)}
    texts: dict[str, list[str]] = {}
    for c in competing_candidates(candidates, start, end, positions):
        texts.setdefault(c.translator, []).append(c.text)
    joined = [" ".join(parts) for parts in texts.values()]
    return [SimilarityPair(a=a, b=b) for a, b in combinations(joined, 2)]


async def score_chunk(
    ctx: StageContext,
    scorer: Scorer | None,
    profile: DocumentProfile,
    bible: Bible,
    ci: ChunkInput,
    candidates: list[Candidate],
    reconciled: ReconcileResult,
    *,
    tier: Reliability,
    diverse: bool,
) -> ChunkScores:
    spans = reconciled.spans
    sources = [span_source_text(ci, s.start, s.end) for s in spans]
    live = [i for i, s in enumerate(spans) if s.text.strip()]
    calls = _ScorerCalls(scorer)

    final_pairs = [SimilarityPair(a=sources[i], b=spans[i].text) for i in live]
    cand_pairs = {i: _candidate_pairs(ci, candidates, spans[i].start, spans[i].end) for i in live}
    all_pairs = final_pairs + [p for i in live for p in cand_pairs[i]]

    judged, roundtrip, qe, sims = await asyncio.gather(
        judge_chunk(ctx, profile, bible, ci, spans),
        back_translate_chunk(ctx, profile, ci, spans),
        calls.qe([QEItem(source=sources[i], hypothesis=spans[i].text) for i in live])
        if live
        else _none(),
        calls.similarity(all_pairs) if all_pairs else _none(),
    )

    bt_texts = roundtrip.texts or [None] * len(spans)
    bt_live = [i for i in live if bt_texts[i]]
    rt_qe, rt_sims = await asyncio.gather(
        calls.qe([QEItem(source="", hypothesis=bt_texts[i] or "", reference=sources[i])
                  for i in bt_live]) if bt_live else _none(),
        calls.similarity([SimilarityPair(a=sources[i], b=bt_texts[i] or "") for i in bt_live])
        if bt_live
        else _none(),
    )

    floor = ctx.cfg.scoring.xsim_floor
    sim_cursor = len(final_pairs)
    by_span: dict[int, dict[str, float | None]] = {}
    for k, i in enumerate(live):
        n_pairs = len(cand_pairs[i])
        cand = sims[sim_cursor : sim_cursor + n_pairs] if sims is not None else []
        sim_cursor += n_pairs
        by_span[i] = {
            "qe": qe[k] if qe is not None else None,
            "xsim": sims[k] if sims is not None else None,
            "cand": normalize_sim(sum(cand) / len(cand), floor) if cand else None,
        }
    for k, i in enumerate(bt_live):
        by_span[i]["rt_qe"] = rt_qe[k] if rt_qe is not None else None
        by_span[i]["rt_sim"] = rt_sims[k] if rt_sims is not None else None

    scores: list[SpanScore] = []
    flags: list[list[Flag]] = []
    for i, rs in enumerate(spans):
        data = by_span.get(i, {})
        signal, violations = bible_check(sources[i], rs.text, bible)
        evidence = SpanEvidence(
            source_text=sources[i],
            final_text=rs.text,
            genre=profile.genre,
            qe_raw=data.get("qe"),
            xsim_cos=data.get("xsim"),
            roundtrip_qe_raw=data.get("rt_qe"),
            roundtrip_cos=data.get("rt_sim"),
            judge_errors=judged.errors_by_span[i] if judged.errors_by_span is not None else None,
            agreement=agreement_signal(rs.agreement, data.get("cand")),
            bible_signal=signal,
            bible_violations=tuple(violations),
            length_ratio=length_ratio(sources[i], rs.text),
        )
        score, span_flags = score_span(evidence, tier=tier, cfg=ctx.cfg.scoring, diverse=diverse)
        scores.append(score)
        flags.append(span_flags)

    run_errors = [*judged.run_errors, *roundtrip.run_errors]
    if calls.error is not None:
        run_errors.append(
            RunError(stage="score", chunk_id=ci.chunk.id, role="scorer", message=calls.error)
        )
    return ChunkScores(
        scores=scores,
        flags=flags,
        judge_errors=judged.errors_by_span or [[] for _ in spans],
        back_translations=[bt_texts[i] if i in live else None for i in range(len(spans))],
        run_errors=run_errors,
    )


async def _none() -> None:
    return None
```

```python
"""MetricX-24 quality estimation (google-research/metricx, Apache-2.0).

MetricX's MT5ForRegression is stock mT5 with a regression read-out: decoder input [0], logit of
token 250089 (<extra_id_10>) clamped to [0, 25]; inputs drop their trailing EOS token.
MT5ForConditionalGeneration has the same parameters and forward pass, so MetricX checkpoints
load into it directly and no model code is vendored."""

from collections.abc import Sequence
from pathlib import Path
from typing import Any

import torch

PREDICTION_TOKEN_ID = 250089
MAX_INPUT_LENGTH = 1536
MAX_SCORE = 25.0


def make_input(source: str, hypothesis: str, reference: str | None) -> str:
    text = f"source: {source} candidate: {hypothesis}"
    return text if reference is None else f"{text} reference: {reference}"


class MetricXQE:
    def __init__(
        self,
        model: Any,
        tokenizer: Any,
        *,
        device: str = "cpu",
        batch_size: int = 8,
        max_input_length: int = MAX_INPUT_LENGTH,
        name: str = "metricx-24",
    ) -> None:
        self.model = model.to(device).eval()
        self.tokenizer = tokenizer
        self.device = device
        self.batch_size = batch_size
        self.max_input_length = max_input_length
        self.name = name

    @classmethod
    def from_pretrained(
        cls, model_path: str, tokenizer_path: str, *, device: str = "cpu", batch_size: int = 8
    ) -> "MetricXQE":
        from transformers import AutoTokenizer, MT5ForConditionalGeneration

        tokenizer = AutoTokenizer.from_pretrained(tokenizer_path, local_files_only=True)
        model = MT5ForConditionalGeneration.from_pretrained(
            model_path, torch_dtype="auto", local_files_only=True
        )
        return cls(model, tokenizer, device=device, batch_size=batch_size,
                   name=Path(model_path).name)

    def _encode(self, texts: list[str]) -> tuple[torch.Tensor, torch.Tensor]:
        encoded = self.tokenizer(texts, max_length=self.max_input_length, truncation=True)
        sequences = [seq[:-1] for seq in encoded["input_ids"]]  # MetricX drops the EOS token
        width = max(1, *(len(s) for s in sequences))
        input_ids = torch.full((len(sequences), width), self.tokenizer.pad_token_id,
                               dtype=torch.long)
        mask = torch.zeros((len(sequences), width), dtype=torch.long)
        for row, seq in enumerate(sequences):
            input_ids[row, : len(seq)] = torch.tensor(seq, dtype=torch.long)
            mask[row, : len(seq)] = 1
        return input_ids.to(self.device), mask.to(self.device)

    def score(self, items: Sequence[tuple[str, str, str | None]]) -> list[float]:
        scores: list[float] = []
        with torch.inference_mode():
            for start in range(0, len(items), self.batch_size):
                batch = items[start : start + self.batch_size]
                input_ids, mask = self._encode([make_input(*item) for item in batch])
                decoder = torch.zeros((len(batch), 1), dtype=torch.long, device=self.device)
                logits = self.model(
                    input_ids=input_ids, attention_mask=mask, decoder_input_ids=decoder
                ).logits
                predictions = logits[:, 0, PREDICTION_TOKEN_ID].float().clamp(0, MAX_SCORE)
                scores.extend(float(p) for p in predictions.tolist())
        return scores
```

```python
"""LaBSE cross-lingual sentence similarity (sentence-transformers/LaBSE, Apache-2.0)."""

from collections.abc import Sequence
from pathlib import Path
from typing import Any

import numpy as np


class LabseEmbedder:
    def __init__(self, model: Any, *, batch_size: int = 32, name: str = "labse") -> None:
        self.model = model
        self.batch_size = batch_size
        self.name = name

    @classmethod
    def from_pretrained(
        cls, path: str, *, device: str = "cpu", batch_size: int = 32
    ) -> "LabseEmbedder":
        import sentence_transformers

        model = sentence_transformers.SentenceTransformer(path, device=device)
        return cls(model, batch_size=batch_size, name=Path(path).name)

    def similarity(self, pairs: Sequence[tuple[str, str]]) -> list[float]:
        texts = list(dict.fromkeys(t for pair in pairs for t in pair if t.strip()))
        if not texts:
            return [0.0] * len(pairs)
        vectors = self.model.encode(
            texts, batch_size=self.batch_size, normalize_embeddings=True, convert_to_numpy=True
        )
        index = {t: i for i, t in enumerate(texts)}
        sims: list[float] = []
        for a, b in pairs:
            if not a.strip() or not b.strip():
                sims.append(0.0)
                continue
            cos = float(np.dot(vectors[index[a]], vectors[index[b]]))
            sims.append(max(-1.0, min(1.0, cos)))
        return sims
```

```python
"""HTTP API of the scorer service. Contract: schema/scorer-*.schema.json (engine-exported)."""

import threading
from typing import Any

from fastapi import FastAPI, HTTPException

from coglossa_scorer.api import (
    QERequest,
    QEResponse,
    ScorerHealth,
    SimilarityRequest,
    SimilarityResponse,
)


def create_app(qe: Any | None, embedder: Any | None, *, device: str) -> FastAPI:
    app = FastAPI(title="coglossa-scorer")
    lock = threading.Lock()  # one inference at a time; endpoints run in FastAPI's threadpool

    @app.get("/health", response_model=ScorerHealth)
    def health() -> ScorerHealth:
        return ScorerHealth(
            qe_model=qe.name if qe is not None else None,
            embed_model=embedder.name if embedder is not None else None,
            device=device,
        )

    @app.post("/v1/qe", response_model=QEResponse)
    def score_qe(request: QERequest) -> QEResponse:
        if qe is None:
            raise HTTPException(status_code=503, detail="quality-estimation model not loaded")
        with lock:
            scores = qe.score([(i.source, i.hypothesis, i.reference) for i in request.items])
        return QEResponse(scores=scores)

    @app.post("/v1/similarity", response_model=SimilarityResponse)
    def similarity(request: SimilarityRequest) -> SimilarityResponse:
        if embedder is None:
            raise HTTPException(status_code=503, detail="embedding model not loaded")
        with lock:
            sims = embedder.similarity([(p.a, p.b) for p in request.pairs])
        return SimilarityResponse(similarities=sims)

    return app
```

```python
from coglossa_scorer.embed import LabseEmbedder

    p = argparse.ArgumentParser(prog="coglossa-scorer", description=__doc__)
    p.add_argument("--qe-model", help="local directory of a MetricX-24 checkpoint")
    p.add_argument("--qe-tokenizer", help="local directory of the mT5 tokenizer "
```
