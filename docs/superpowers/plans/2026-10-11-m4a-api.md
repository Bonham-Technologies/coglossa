# Coglossa M4a — Ingestors, Exports and REST API: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything the web app needs from the server side (spec §8, §7.5, §4.1, milestone M4). M4a adds:
- **Ingestors** for HTML, EPUB and PDFs with a text layer. A scanned PDF stops with `needs_ocr`.
- **Exports:** a standalone HTML page, a bilingual side-by-side DOCX with flags as Word comments, and a clean DOCX in the target language. All of them show the current revisions.
- **Review operations:** read spans with filters, edit a span, use a candidate, accept a span, accept/dismiss/reopen flags, add terms and names to the bible. Every action is written to `review_event` (spec §6.5).
- **Bible management:** versions per project, saving an edited bible, re-running the sweep after a locked term changes.
- **A REST API** (`api/`, FastAPI): projects, uploads, runs, progress over SSE, bible, review, report and exports, and the System page data (doctor, config, language tiers). Its OpenAPI document is committed in `schema/openapi.json`.

M4 is split in two. **M4b (the React web app, generated TypeScript types and Playwright journeys) gets its own plan**, written against this API once it is merged.

**Architecture:**
- **The library stays pure.** The new ingestors (`coglossa.ingest.html`, `.epub`, `.pdf`) and exports (`coglossa.export`) take files or a `Report` and never touch the database.
- **The control plane grows two modules on top of `coglossa.store`:**
  - `coglossa.catalog`: projects, documents, runs and bible versions, in the shapes the API returns.
  - `coglossa.review`: span pages and details, and the review actions.

  `coglossa.service` gains upload submission, a new run for an existing document, and re-running the sweep.
- **The API is a thin HTTP layer.** `api/coglossa_api` (its own uv project, depending on the engine by path) maps routes to `service`, `catalog` and `review` calls and maps their exceptions to status codes. It never calls a model. The one exception is doctor, which checks the backends by design (spec §7.4).
- **Read models** (`coglossa.schema.views`) are Pydantic models shared by the control plane and the API, so the OpenAPI document describes exactly what the service returns.

**Tech Stack:**
- Unchanged from M3: Python ≥3.12, uv, Pydantic v2, SQLAlchemy 2 asyncio + psycopg 3, Alembic, procrastinate 3.10, pytest + Hypothesis, ruff.
- New engine dependencies:
  - `lxml` for HTML and EPUB
  - `pdfminer.six` for PDF
  - `python-docx>=1.2` for Word comments
- New `api/` project: FastAPI, uvicorn, python-multipart.

  - `api/pyproject.toml`:

    - `python-multipart>=0.0.18`
- **The API package:**
  - It lives at `api/`, with package `coglossa_api` and console script `coglossa-api`.
  - It depends on the engine through `[tool.uv.sources] coglossa = { path = "../engine", editable = true }`.
  - It uses the same ruff settings as the engine and its own coverage gate.
  - Its tests use the same Postgres test database setup (`COGLOSSA_TEST_DATABASE_URL`, throwaway database per session) through `coglossa.testing.postgres`.
- **API conventions:**
  - Every route is under `/api`. Request and response bodies are JSON, except the upload (multipart) and the exports (files).
  - IDs: projects, documents, runs and spans are UUID strings; flags are integers (`flag.id`).
  - Errors are `{"detail": "<one line safe to show a user>"}`:

    | Status | When |
    |---|---|
    | 404 | `NotFoundError` |
    | 409 | `ConflictError`, which includes `InvalidRunStateError` |
    | 413 | the upload is too large |
    | 422 | `InvalidRequestError`, `IngestError`, and FastAPI's own validation errors (which keep FastAPI's list format) |
    | 401 | a missing trusted header |
    | 503 | database unreachable (`DB_ERRORS`) |
    | 500 | `ConfigError`, `StorageError` (their messages are operator-safe) and anything else (`"internal error"`, logged with its traceback) |
  - A response never contains a traceback, a database URL or a password.
- **Auth** (spec §3): `auth.mode` is `none` or `trusted_header`.
  - With `trusted_header`, every `/api` route except `/api/health` requires the configured header (default `X-Remote-User`) with a non-blank value; otherwise it returns 401.
  - The name is recorded as `"user"` in every `review_event` payload. With `none` it is `null`.
- **Review actions** (spec §8.4, §6.5):
  - Every edit, candidate selection, accept, flag status change and bible addition writes one `review_event` row in the same transaction as the change.
  - Revisions are append-only. A user change is a `revision` with `source = "user"` and a reason.
  - Review actions take the run row lock and are refused (409) while the run is `sweeping`, so a sweep never overwrites a change it did not see.
- **Bible versions** are append-only. A version saved by a person (`author = "user"`) is `approved`. Saving from the editor names the version it was based on. If the project has a newer version, the save is refused (409), so no one silently overwrites someone else's save.
- **Exports reflect the current revisions** (spec §7.5): they read `service.build_report`, whose span text is the latest revision. The HTML export is one self-contained file: no scripts, no external fonts or stylesheets, and `dir="auto"` on every text cell.
- **Uploads:**
  - They are limited to `api.max_upload_mb` (413 beyond it).
  - The stored key uses `safe_filename`, but `document.filename` keeps the uploaded name (without any path) for display and export names.
  - Stored files are written with mode `0640` and fsynced before the rename.
  - A failed submit leaves no stored file behind.
- **No transaction is held across slow work.** The API never calls a model. Doctor runs outside any database session. Exports are built after the report's session closes.
- **Every new user-facing message** is one line, says what happened, and says what to do when there is something to do.

## Review Focus

These are inputs the spec implies but no task's main tests exercise. Each gets a test in the task named.

1. **A reviewer acts while the sweep runs, or two reviewers change the same passage.** The action is refused with 409 and a message saying to try again when the sweep finishes. Two edits in a row both appear in the revision history, and the later one is the current text (Task 11: edit while `sweeping`, two sequential edits; Task 14: the 409 over HTTP).
2. **Non-ASCII, right-to-left and path-like file names** (`رواية.txt`, `café notes.docx`, `../../etc/passwd.txt`). The upload is stored under a safe key. `document.filename` keeps the visible name without directories. Export downloads carry a correct RFC 5987 `Content-Disposition` header (Task 7: `submit_bytes` with these names; Task 14: download header).
3. **Bad uploads:** too large, empty, unsupported extension, no file name.
   - Too large: 413 and nothing stored.
   - Empty or unsupported: 422 with the reason (the supported extensions for an unsupported type).
   - No file name: 422.
   - No run is created in any of these cases (Task 13).
4. **A scanned PDF, a DRM-protected EPUB or a damaged file reaches the worker.** The run fails at ingest with one line naming the problem (`needs OCR … page 2`, `DRM-protected`, `not a readable … file`). The worker keeps running (Tasks 3 and 4: ingestor messages; Task 16: a queued scanned PDF ends `failed` with that message).
5. **Review changes must reach the exports.** After an edit, a used candidate and a dismissed flag:
   - the report, HTML and both DOCX exports contain the edited text
   - the dismissed flag is neither listed nor commented
   - the original text survives in the revision history.

   (Task 6: dismissed flags are not commented; Task 16: end to end over HTTP.)

```python
"""Read models the REST API returns (spec §8). The control plane builds them and the API
serves them unchanged, so the OpenAPI document describes exactly what the service returns.
IDs are strings: UUIDs for projects, documents, runs and spans; integers for flags."""

from datetime import datetime
from enum import StrEnum
from typing import Annotated, Any, Literal

from pydantic import BaseModel, Field

from coglossa.schema.bible import Bible
from coglossa.schema.profile import DocumentProfile, PipelineProfile
from coglossa.schema.run import RunProgress, RunState
from coglossa.schema.translation import (
    Agreement,
    Candidate,
    Flag,
    FlagCode,
    FlagStatus,
    JudgeError,
    Reliability,
    RevisionSource,
    SpanScore,
)

# BCP-47-like: a 2–3 letter language, then optional subtags (script, region, variant).
LANGUAGE_CODE_PATTERN = r"^[A-Za-z]{2,3}(?:[-_][A-Za-z0-9]{1,8})*$"
LanguageCode = Annotated[str, Field(pattern=LANGUAGE_CODE_PATTERN, max_length=35)]


class ProjectInfo(BaseModel):
    id: str
    name: str
    target_lang: str | None  # default for new runs; None for projects made by the CLI
    source_lang: str | None  # None: detected per document
    pipeline_profile: PipelineProfile | None  # None: chosen per document
    created_at: datetime
    documents: int
    runs: int
    bible_version: int | None  # the latest version number; None: no bible yet


class RunSummary(BaseModel):
    id: str
    project_id: str
    document_id: str
    filename: str
    state: RunState
    target_lang: str
    source_lang: str | None  # detected once profiled, else the requested override
    pipeline_profile: PipelineProfile | None  # chosen once profiled, else the override
    created_at: datetime
    started_at: datetime | None
    finished_at: datetime | None
    error: str | None


class DocumentSummary(BaseModel):
    id: str
    project_id: str
    filename: str
    format: str
    created_at: datetime
    ingested: bool
    runs: list[RunSummary]  # newest first


class ReviewStats(BaseModel):
    spans: int
    open_flags: int
    flags_by_code: dict[str, int]  # open flags only
    edited_spans: int  # spans with at least one user revision


class RunDetail(BaseModel):
    run: RunSummary
    progress: RunProgress
    profile: DocumentProfile | None  # None until profiled
    language_tier: Reliability | None
    notices: list[Flag]  # document-level notices (spec §6.4), once passages exist
    summary: str | None  # the bible's summary, once the bible exists
    bible_version: int | None
    stats: ReviewStats
    report_available: bool  # complete or complete_with_errors


class BibleVersionInfo(BaseModel):
    version: int
    status: Literal["draft", "approved"]
    author: Literal["engine", "user"]
    source_run_id: str | None
    created_at: datetime


class BibleView(BaseModel):
    info: BibleVersionInfo
    bible: Bible


class ReviewFlag(BaseModel):
    id: int
    code: FlagCode
    explanation: str
    evidence: dict[str, Any] = Field(default_factory=dict)
    status: FlagStatus
    dismiss_reason: str | None = None


class ReviewSpan(BaseModel):
    id: str
    number: int  # 1-based reading-order position; the report calls this span p<number>
    chunk_id: str
    start: str
    end: str
    source: str
    text: str  # the latest revision
    agreement: Agreement
    score: SpanScore  # describes the reviewed draft, not later edits
    flags: list[ReviewFlag]
    edited: bool  # a person changed the text


class SpanPage(BaseModel):
    total: int  # spans matching the filter
    offset: int
    limit: int
    spans: list[ReviewSpan]


class RevisionEntry(BaseModel):
    source: RevisionSource
    before: str | None
    after: str
    reason: str
```

- Produces:
  - `Item = tuple[BlockKind, str, str | None]`
  - `parse_html(data: bytes) -> lxml.html.HtmlElement | None` (None for an empty document)
  - `collect_blocks(root, locator: str | None) -> list[Item]`
  - `HtmlIngestor` (format `html`, extensions `.html`, `.htm`, `.xhtml`), registered in `available_ingestors()`.

**Block rules** (for the implementer and the reviewer):

| Element | Becomes |
|---|---|
| `h1`–`h6` | `heading` |
| `li` | `list_item` |
| `td`, `th` | `table_cell` |
| an element with `epub:type` `footnote`/`endnote`/`rearnote`/`note`, or `role` `doc-footnote`/`doc-endnote` | `footnote` |
| `hr` | a `break` with text `* * *` |
| other text | `paragraph`; a paragraph whose whole text is a scene-break marker becomes a `break` |

- **Nesting:** block elements nested inside these keep the outer kind, so `<li><p>` is a list item and `<td><p>` a table cell.
- **Flushing:** text before, between and after child blocks becomes its own block.
- **Line breaks:** `br` becomes a line break inside the block.
- **Whitespace:** runs of whitespace collapse to one space.
- **`pre`:** keeps its line breaks.
- **Skipped:** `head`, `script`, `style`, `noscript`, `template`, `svg`, `math`, `iframe`, `object`, form controls, comments, and note-reference markers (`epub:type="noteref"`, `role="doc-noteref"`). Their tail text is kept.
- **Encoding:** UTF-8 is assumed. Bytes that are not valid UTF-8 go to lxml, which honours the document's `<meta charset>`.

```python
"""HTML ingestion (spec §4.1), also used for the XHTML chapters of EPUB files. Block-level
elements become blocks in document order: headings, paragraphs, list items, table cells,
footnotes and breaks. Inline markup is flattened to its text; the head, scripts, styles,
comments and note-reference markers are skipped."""

import re
from pathlib import Path
from typing import Any

import lxml.html
from lxml import etree

from coglossa.ingest.base import file_sha256, is_scene_break, make_blocks, strip_nul
from coglossa.schema import BlockKind, SourceDocument

Item = tuple[BlockKind, str, str | None]

_SKIP = frozenset(
    {
        "head",
        "script",
        "style",
        "noscript",
        "template",
        "svg",
        "math",
        "iframe",
        "object",
        "select",
        "textarea",
        "button",
    }
)
_HEADINGS = frozenset({"h1", "h2", "h3", "h4", "h5", "h6"})
_KIND_OF_TAG = {
    **{h: BlockKind.HEADING for h in _HEADINGS},
    "li": BlockKind.LIST_ITEM,
    "td": BlockKind.TABLE_CELL,
    "th": BlockKind.TABLE_CELL,
}
_BLOCK_TAGS = _HEADINGS | {
    "html",
    "body",
    "p",
    "div",
    "section",
    "article",
    "aside",
    "header",
    "footer",
    "main",
    "nav",
    "blockquote",
    "pre",
    "ul",
    "ol",
    "dl",
    "dt",
    "dd",
    "li",
    "table",
    "thead",
    "tbody",
    "tfoot",
    "tr",
    "td",
    "th",
    "caption",
    "figure",
    "figcaption",
    "address",
    "details",
    "summary",
    "hgroup",
    "center",
    "form",
    "fieldset",
    "legend",
}
_FOOTNOTE_TYPES = frozenset({"footnote", "endnote", "rearnote", "note"})
_FOOTNOTE_ROLES = frozenset({"doc-footnote", "doc-endnote"})
_NOTEREF_TYPES = frozenset({"noteref"})
_LINE_BREAK = ""  # stands for <br> until whitespace is normalized
_WHITESPACE = re.compile(r"\s+")
_XML_DECLARATION = re.compile(r"^\s*<\?xml[^>]*\?>")


def _tag(el: Any) -> str | None:
    if not isinstance(el.tag, str):
        return None  # a comment or processing instruction
    return el.tag.rsplit("}", 1)[-1].lower()


def _epub_types(el: Any) -> set[str]:
    return set((el.get("epub:type") or "").split())


def _is_footnote(el: Any) -> bool:
    return bool(_epub_types(el) & _FOOTNOTE_TYPES) or el.get("role") in _FOOTNOTE_ROLES


def _is_noteref(el: Any) -> bool:
    return bool(_epub_types(el) & _NOTEREF_TYPES) or el.get("role") == "doc-noteref"


def _normalize(text: str) -> str:
    lines = (_WHITESPACE.sub(" ", line).strip() for line in strip_nul(text).split(_LINE_BREAK))
    return "\n".join(line for line in lines if line)


class _Collector:
    def __init__(self, locator: str | None) -> None:
        self.locator = locator
        self.items: list[Item] = []
        self._buffer: list[str] = []
        self._kinds: list[BlockKind] = [BlockKind.PARAGRAPH]

    def flush(self) -> None:
        text = _normalize("".join(self._buffer))
        self._buffer.clear()
        if not text:
            return
        kind = self._kinds[-1]
        if kind is BlockKind.PARAGRAPH and is_scene_break(text):
            kind = BlockKind.BREAK
        self.items.append((kind, text, self.locator))

    def walk(self, el: Any) -> None:
        tag = _tag(el)
        if tag is None or tag in _SKIP or _is_noteref(el):
            return  # the caller keeps the element's tail text
        if tag == "br":
            self._buffer.append(_LINE_BREAK)
            return
        if tag == "hr":
            self.flush()
            self.items.append((BlockKind.BREAK, "* * *", self.locator))
            return
        footnote = _is_footnote(el)
        block = footnote or tag in _BLOCK_TAGS
        if block:
            self.flush()
            kind = BlockKind.FOOTNOTE if footnote else _KIND_OF_TAG.get(tag, self._kinds[-1])
            self._kinds.append(kind)
        if tag == "pre":
            self._buffer.append(el.text_content().replace("\n", _LINE_BREAK))
        else:
            if el.text:
                self._buffer.append(el.text)
            for child in el:
                self.walk(child)
                if child.tail:
                    self._buffer.append(child.tail)
        if block:
            self.flush()
            self._kinds.pop()


def parse_html(data: bytes) -> Any | None:
    """The document's root element, or None for an empty document. UTF-8 is assumed; bytes
    that are not valid UTF-8 go to lxml, which honours the document's declared charset."""
    source: str | bytes
    try:
        source = _XML_DECLARATION.sub("", data.decode("utf-8-sig"), count=1)
    except UnicodeDecodeError:
        source = data
    if not source.strip():
        return None
    try:
        return lxml.html.document_fromstring(source)
    except etree.ParserError:  # "Document is empty": only comments or whitespace
        return None


def collect_blocks(root: Any, locator: str | None) -> list[Item]:
    collector = _Collector(locator)
    collector.walk(root)
    collector.flush()
    return collector.items


class HtmlIngestor:
    format = "html"
    extensions = (".html", ".htm", ".xhtml")

    def ingest(self, path: Path) -> SourceDocument:
        root = parse_html(path.read_bytes())
        items = collect_blocks(root, None) if root is not None else []
        return SourceDocument(
            source_path=str(path),
            format=self.format,
            sha256=file_sha256(path),
            blocks=make_blocks(str(path), items),
        )
```

**Files:**

**Interfaces:**
- Consumes: `parse_html`, `collect_blocks`, `Item` (Task 2); `IngestError`, `file_sha256`, `make_blocks`.
- Produces: `EpubIngestor` (format `epub`, extension `.epub`) and `MAX_UNCOMPRESSED_BYTES`.

**Rules:**
- **Reading order:** chapters follow the spine. Every spine item that is XHTML or HTML is read, whether or not it is `linear="no"`; translators should see everything. Manifest items outside the spine (the navigation document, CSS, images) are skipped.
- **Locator:** a block's locator is its chapter's path inside the EPUB, percent-decoded and relative to the zip root.
- **XML parsing:** `META-INF/container.xml` and the package document are parsed with entities and DTDs disabled and no network access.
- **DRM:** a book whose `META-INF/encryption.xml` lists a spine chapter is DRM-protected and refused. Font obfuscation (an encryption file listing only fonts) is accepted.
- **Size limit:** an archive whose members expand to more than `MAX_UNCOMPRESSED_BYTES` (512 MB) is refused before anything is decompressed.
- **Damaged files:** any other failure is `"<name> is not a readable EPUB file (<reason>)"`.

```python
"""EPUB ingestion (spec §4.1): the chapters in reading (spine) order, each parsed like HTML.
A block's locator is its chapter's path inside the EPUB. DRM-protected books are refused;
font obfuscation alone is not DRM."""

import posixpath
import zipfile
from pathlib import Path
from typing import Any
from urllib.parse import unquote

from lxml import etree

from coglossa.ingest.base import IngestError, file_sha256, make_blocks
from coglossa.ingest.html import Item, collect_blocks, parse_html
from coglossa.schema import SourceDocument

MAX_UNCOMPRESSED_BYTES = 512 * 1024 * 1024
_CHAPTER_TYPES = frozenset({"application/xhtml+xml", "text/html"})
# Package files come from untrusted books: no entity expansion, DTDs or network access.
_XML_PARSER = etree.XMLParser(resolve_entities=False, no_network=True, load_dtd=False)


class _Unreadable(ValueError):
    pass


def _xml(z: zipfile.ZipFile, name: str) -> Any:
    try:
        return etree.fromstring(z.read(name), parser=_XML_PARSER)
    except etree.XMLSyntaxError as e:
        raise _Unreadable(f"{name}: {e}") from e


def _chapters(z: zipfile.ZipFile) -> list[str]:
    container = _xml(z, "META-INF/container.xml")
    rootfiles = container.xpath("//*[local-name()='rootfile']/@full-path")
    if not rootfiles:
        raise _Unreadable("META-INF/container.xml names no package document")
    opf_path = str(rootfiles[0])
    opf = _xml(z, opf_path)
    base = posixpath.dirname(opf_path)
    manifest: dict[str, tuple[str, str]] = {}
    for item in opf.xpath("//*[local-name()='manifest']/*[local-name()='item']"):
        href = posixpath.normpath(posixpath.join(base, unquote(item.get("href", ""))))
        manifest[item.get("id", "")] = (href, item.get("media-type", ""))
    chapters = []
    for idref in opf.xpath("//*[local-name()='spine']/*[local-name()='itemref']/@idref"):
        href, media_type = manifest.get(str(idref), ("", ""))
        if media_type in _CHAPTER_TYPES:
            chapters.append(href)
    if not chapters:
        raise _Unreadable("its spine lists no chapters")
    return chapters


def _encrypted(z: zipfile.ZipFile) -> set[str]:
    if "META-INF/encryption.xml" not in z.namelist():
        return set()
    uris = _xml(z, "META-INF/encryption.xml").xpath("//*[local-name()='CipherReference']/@URI")
    return {posixpath.normpath(unquote(str(u))) for u in uris}


class EpubIngestor:
    format = "epub"
    extensions = (".epub",)

    def ingest(self, path: Path) -> SourceDocument:
        try:
            with zipfile.ZipFile(path) as z:
                if sum(info.file_size for info in z.infolist()) > MAX_UNCOMPRESSED_BYTES:
                    raise IngestError(
                        f"{path.name} expands to more than {MAX_UNCOMPRESSED_BYTES // 2**20} MB; "
                        "split the book and retry"
                    )
                chapters = _chapters(z)
                if _encrypted(z) & set(chapters):
                    raise IngestError(
                        f"{path.name} is DRM-protected; only DRM-free EPUB files can be translated"
                    )
                items: list[Item] = []
                for href in chapters:
                    root = parse_html(z.read(href))
                    if root is not None:
                        items += collect_blocks(root, href)
        except (IngestError, OSError):
            raise  # OSError: the registry reports "cannot be read"
        except Exception as e:  # zipfile, zlib and lxml raise many unrelated types
            raise IngestError(f"{path.name} is not a readable EPUB file ({e})") from e
        return SourceDocument(
            source_path=str(path),
            format=self.format,
            sha256=file_sha256(path),
            blocks=make_blocks(str(path), items),
        )
```

Register it in `engine/coglossa/ingest/registry.py`: `from coglossa.ingest.epub import EpubIngestor`, and append `EpubIngestor()` to the built-in list.

An empty zip raises `KeyError: "There is no item named 'META-INF/container.xml' in the archive"`. `make_epub(..., spine=[])` gives "lists no chapters".

**Rules** (spec §4.1: "If a PDF page has no text layer, ingest reports `needs_ocr` and stops"):
- **Blocks:** each text box pdfminer finds (`LAParams(all_texts=True)`, so text inside form XObjects counts) becomes a `paragraph` block with `provenance.page` = the 1-based page number and `locator = "page N"`.
- **Line breaks:** inside a box they become spaces. A hyphen at a line end followed by a lowercase letter is removed (`conti-\nnue` → `continue`).
- **Dropped boxes:** boxes that are only a 1–4 digit number (page numbers) are dropped.
- **Scanned pages:** a page with an image and no text is scanned. After reading every page, if any page was scanned, ingest raises `NeedsOCRError`:

  ```
  <name> needs OCR (needs_ocr): page(s) 2, 5 have no text layer; scanned pages are not supported yet, use a PDF with a text layer
  ```
- **Blank pages:** a page with neither text nor image is skipped.
- **Errors:**
  - a PDF with no pages: `"<name> is not a readable PDF file (it has no pages)"`
  - a wrong password: `"<name> is password-protected; remove the password and retry"`
  - anything else pdfminer raises: `"<name> is not a readable PDF file (<Type>: <message>)"`

```python
"""Builds small PDFs for tests: text pages (Helvetica, WinAnsi encoding), image-only
"scanned" pages and blank pages. Paragraphs are drawn 40 points apart, so pdfminer sees
each one as its own text box; "\\n" inside a paragraph starts a new line 14 points down."""


def _escape(text: str) -> bytes:
    raw = text.encode("cp1252")
    return raw.replace(b"\\", b"\\\\").replace(b"(", b"\\(").replace(b")", b"\\)")


def _text_stream(paragraphs: list[str]) -> bytes:
    out = [b"BT /F1 12 Tf 14 TL"]
    y = 760
    for paragraph in paragraphs:
        lines = paragraph.split("\n")
        out.append(b"1 0 0 1 72 %d Tm" % y)
        for i, line in enumerate(lines):
            if i:
                out.append(b"T*")
            out.append(b"(" + _escape(line) + b") Tj")
        y -= 14 * len(lines) + 40
    out.append(b"ET")
    return b"\n".join(out)


_IMAGE_PAGE = b"q 200 0 0 200 100 400 cm /Im1 Do Q"


def make_pdf(pages: list[list[str] | str]) -> bytes:
    """pages: per page, a list of paragraphs, [] for a blank page, or "image" for a page
    that shows a picture and has no text (a scanned page)."""
    objects: list[bytes] = [b"", b""]  # 1: catalog, 2: page tree (filled in at the end)
    objects.append(
        b"<< /Type /Font /Subtype /Type1 /BaseFont /Helvetica /Encoding /WinAnsiEncoding >>"
    )
    font = len(objects)
    objects.append(
        b"<< /Type /XObject /Subtype /Image /Width 1 /Height 1 /ColorSpace /DeviceGray "
        b"/BitsPerComponent 8 /Length 1 >>\nstream\n\x80\nendstream"
    )
    image = len(objects)
    kids = []
    for page in pages:
        content = _IMAGE_PAGE if page == "image" else _text_stream(list(page))
        objects.append(b"<< /Length %d >>\nstream\n" % len(content) + content + b"\nendstream")
        stream = len(objects)
        objects.append(
            b"<< /Type /Page /Parent 2 0 R /MediaBox [0 0 612 792] /Resources << /Font "
            b"<< /F1 %d 0 R >> /XObject << /Im1 %d 0 R >> >> /Contents %d 0 R >>"
            % (font, image, stream)
        )
        kids.append(len(objects))
    objects[0] = b"<< /Type /Catalog /Pages 2 0 R >>"
    objects[1] = b"<< /Type /Pages /Kids [%s] /Count %d >>" % (
        b" ".join(b"%d 0 R" % k for k in kids),
        len(kids),
    )
    out = bytearray(b"%PDF-1.4\n%\xe2\xe3\xcf\xd3\n")
    offsets = []
    for number, body in enumerate(objects, start=1):
        offsets.append(len(out))
        out += b"%d 0 obj\n" % number + body + b"\nendobj\n"
    xref = len(out)
    out += b"xref\n0 %d\n0000000000 65535 f \n" % (len(objects) + 1)
    for offset in offsets:
        out += b"%010d 00000 n \n" % offset
    out += b"trailer\n<< /Size %d /Root 1 0 R >>\nstartxref\n%d\n%%%%EOF\n" % (
        len(objects) + 1,
        xref,
    )
    return bytes(out)
```

```python
"""PDF ingestion for PDFs with a text layer (spec §4.1). Each text box pdfminer finds becomes
a paragraph with its page number. A page that shows an image but has no text is a scanned
page: ingest stops with needs_ocr, since OCR is a later sub-project. Bare page numbers are
dropped; blank pages are skipped."""

import re
from collections.abc import Iterator
from pathlib import Path
from typing import Any

from pdfminer.high_level import extract_pages
from pdfminer.layout import LAParams, LTFigure, LTImage, LTTextContainer
from pdfminer.pdfdocument import PDFPasswordIncorrect

from coglossa.ingest.base import IngestError, file_sha256, strip_nul
from coglossa.schema import Block, BlockKind, Provenance, SourceDocument

_HYPHENATED = re.compile(r"(\w)-\n(\w)")
_WHITESPACE = re.compile(r"\s+")
_PAGE_NUMBER = re.compile(r"^\d{1,4}$")


class NeedsOCRError(IngestError):
    def __init__(self, filename: str, pages: list[int]) -> None:
        self.pages = pages
        super().__init__(
            f"{filename} needs OCR (needs_ocr): page(s) {', '.join(map(str, pages))} have no "
            "text layer; scanned pages are not supported yet, use a PDF with a text layer"
        )


def _join_hyphenated(match: re.Match[str]) -> str:
    before, after = match.group(1), match.group(2)
    return before + after if after.islower() else match.group(0)


def _clean(raw: str) -> str:
    text = _HYPHENATED.sub(_join_hyphenated, strip_nul(raw))
    return _WHITESPACE.sub(" ", text).strip()


def _walk(elements: Any) -> Iterator[Any]:
    for element in elements:
        yield element
        if isinstance(element, LTFigure):
            yield from _walk(element)


def _page_content(page: Any) -> tuple[list[str], bool]:
    texts: list[str] = []
    has_image = False
    for element in _walk(page):
        if isinstance(element, LTTextContainer):
            text = _clean(element.get_text())
            if text and not _PAGE_NUMBER.match(text):
                texts.append(text)
        elif isinstance(element, LTImage):
            has_image = True
    return texts, has_image


class PdfIngestor:
    format = "pdf"
    extensions = (".pdf",)

    def ingest(self, path: Path) -> SourceDocument:
        blocks: list[Block] = []
        scanned: list[int] = []
        pages = 0
        try:
            for number, page in enumerate(
                extract_pages(path, laparams=LAParams(all_texts=True)), start=1
            ):
                pages = number
                texts, has_image = _page_content(page)
                if not texts and has_image:
                    scanned.append(number)
                for text in texts:
                    index = len(blocks)
                    blocks.append(
                        Block(
                            id=f"b{index + 1}",
                            kind=BlockKind.PARAGRAPH,
                            text=text,
                            provenance=Provenance(
                                source_path=str(path),
                                index=index,
                                page=number,
                                locator=f"page {number}",
                            ),
                        )
                    )
        except PDFPasswordIncorrect as e:
            raise IngestError(f"{path.name} is password-protected; remove the password and retry") from e
        except OSError:
            raise  # the registry reports "cannot be read"
        except Exception as e:  # pdfminer raises many unrelated types for damaged files
            raise IngestError(
                f"{path.name} is not a readable PDF file ({type(e).__name__}: {e})"
            ) from e
        if not pages:
            raise IngestError(f"{path.name} is not a readable PDF file (it has no pages)")
        if scanned:
            raise NeedsOCRError(path.name, scanned)
        return SourceDocument(
            source_path=str(path), format=self.format, sha256=file_sha256(path), blocks=blocks
        )
```

```python
"""What every export shows (spec §7.5): the spans with their source text in reading order,
and the translated text of each source block. Exports read the Report, whose span text is
always the latest revision, so they reflect every sweep and reviewer change."""

from dataclasses import dataclass
from pathlib import PurePosixPath

from coglossa.schema import Block, BlockKind, Flag, FlagStatus, Report, Span
from coglossa.stages.sweep import span_sources

BREAK_MARKER = "* * *"
_RTL_LANGUAGES = frozenset({"ar", "arc", "ckb", "dv", "fa", "he", "iw", "ps", "sd", "ug", "ur", "yi"})
_RTL_SCRIPTS = frozenset({"arab", "hebr", "syrc", "thaa", "nkoo", "adlm", "rohg"})


@dataclass(frozen=True)
class ExportRow:
    number: int  # 1-based reading-order position (the report's p<number>)
    source: str
    span: Span

    @property
    def open_flags(self) -> list[Flag]:
        return [f for f in self.span.flags if f.status is FlagStatus.OPEN]


def export_rows(report: Report) -> list[ExportRow]:
    sources = span_sources(report.spans, report.segments)
    return [
        ExportRow(number=n, source=source, span=span)
        for n, (source, span) in enumerate(zip(sources, report.spans, strict=True), start=1)
    ]


@dataclass(frozen=True)
class TranslatedBlock:
    block: Block
    text: str


def translated_blocks(report: Report) -> list[TranslatedBlock]:
    """Each source block with the translation of the spans that start in it (a span merged
    across blocks belongs to the block it starts in). Breaks keep a marker; blocks left
    without text (their sentences went to an earlier block's span) are left out."""
    block_of = {seg.id: seg.block_id for seg in report.segments}
    texts: dict[str, list[str]] = {}
    for span in report.spans:
        if span.text.strip():
            texts.setdefault(block_of[span.start], []).append(span.text)
    out: list[TranslatedBlock] = []
    for block in report.blocks:
        if block.kind is BlockKind.BREAK:
            out.append(TranslatedBlock(block=block, text=BREAK_MARKER))
        elif block.id in texts:
            out.append(TranslatedBlock(block=block, text=" ".join(texts[block.id])))
    return out


def export_basename(report: Report) -> str:
    stem = PurePosixPath(report.document.source_path.replace("\\", "/")).stem or "document"
    return f"{stem}.{report.profile.target_lang}"


def is_rtl(lang: str) -> bool:
    """Right-to-left by language or by an explicit script subtag (az-Arab)."""
    parts = lang.replace("_", "-").lower().split("-")
    return parts[0] in _RTL_LANGUAGES or any(p in _RTL_SCRIPTS for p in parts[1:])
```

```python
"""Standalone HTML export (spec §7.5): the summary, the document notices and a side-by-side
table of source and translation with scores and open flags. One self-contained file: no
scripts and no external fonts, images or stylesheets, so it opens offline. Every text cell
has dir="auto" so right-to-left scripts display correctly (spec §8)."""

from html import escape
from pathlib import PurePosixPath

from coglossa.export.rows import export_rows
from coglossa.schema import Report

_STYLE = """
body { font-family: "Noto Sans", "Segoe UI", system-ui, sans-serif; margin: 2rem; color: #1b1b1f;
  background: #fff; }
h1 { font-size: 1.4rem; margin-bottom: 0.25rem; }
.meta { color: #55555c; margin-top: 0; }
.notice { background: #fff4d6; border-left: 4px solid #c98a00; padding: 0.5rem 0.75rem; }
table { border-collapse: collapse; width: 100%; table-layout: fixed; }
th, td { border: 1px solid #d0d0d6; padding: 0.4rem 0.5rem; vertical-align: top;
  text-align: start; overflow-wrap: anywhere; }
th { background: #f2f2f5; }
th:nth-child(1), th:nth-child(4), th:nth-child(5) { width: 3.5rem; }
th:nth-child(6) { width: 22%; }
tr.flagged td:first-child { border-left: 4px solid #c0392b; }
td ul { margin: 0; padding-inline-start: 1.1rem; }
""".strip()


def _score(value: float | None) -> str:
    return "—" if value is None else f"{value:.0f}"


def _text(value: str) -> str:
    return escape(value).replace("\n", "<br>")


def render_html(report: Report) -> str:
    rows = export_rows(report)
    src = escape(report.profile.source_lang)
    tgt = escape(report.profile.target_lang)
    name = escape(PurePosixPath(report.document.source_path.replace("\\", "/")).name)
    open_count = sum(len(r.open_flags) for r in rows)
    flag_word = "flag" if open_count == 1 else "flags"
    parts = [
        "<!doctype html>",
        f'<html lang="{tgt}">',
        "<head>",
        '<meta charset="utf-8">',
        '<meta name="viewport" content="width=device-width, initial-scale=1">',
        f"<title>{name} ({src} → {tgt})</title>",
        f"<style>\n{_STYLE}\n</style>",
        "</head>",
        "<body>",
        f"<h1>{name}</h1>",
        f'<p class="meta">{src} → {tgt} · {escape(report.status.value)} · {len(rows)} passages · '
        f"{open_count} open {flag_word}</p>",
    ]
    for notice in report.notices:
        parts.append(f'<p class="notice" role="note">{escape(notice.explanation)}</p>')
    if report.bible.summary.strip():
        parts.append(
            f'<section><h2>Summary</h2><p dir="auto">{_text(report.bible.summary)}</p></section>'
        )
    parts.append(
        "<table><thead><tr><th>#</th><th>Source</th><th>Translation</th><th>Meaning</th>"
        "<th>Style</th><th>Flags</th></tr></thead><tbody>"
    )
    for row in rows:
        flagged = ' class="flagged"' if row.open_flags else ""
        items = "".join(
            f"<li><b>{escape(f.code.value)}</b>: {escape(f.explanation)}</li>"
            for f in row.open_flags
        )
        flags = f"<ul>{items}</ul>" if items else ""
        score = row.span.score
        parts.append(
            f'<tr id="p{row.number}"{flagged}><td>{row.number}</td>'
            f'<td dir="auto" lang="{src}">{_text(row.source)}</td>'
            f'<td dir="auto" lang="{tgt}">{_text(row.span.text)}</td>'
            f"<td>{_score(score.meaning)}</td><td>{_score(score.style)}</td><td>{flags}</td></tr>"
        )
    parts += ["</tbody></table>", "</body>", "</html>"]
    return "\n".join(parts) + "\n"
```

```python
"""DOCX exports (spec §7.5): a bilingual side-by-side table with the open flags added as Word
comments on the translation, and a clean document in the target language that keeps the
source's headings, paragraphs, list items and breaks (table cells become paragraphs)."""

import io
from pathlib import PurePosixPath
from typing import Any

import docx
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.shared import Pt

from coglossa.export.rows import (
    BREAK_MARKER,
    export_basename,
    export_rows,
    is_rtl,
    translated_blocks,
)
from coglossa.schema import BlockKind, Report

COMMENT_AUTHOR = "Coglossa"
COMMENT_INITIALS = "CG"


def _save(document: Any) -> bytes:
    buffer = io.BytesIO()
    document.save(buffer)
    return buffer.getvalue()


def _new_document(report: Report) -> Any:
    document = docx.Document()
    document.core_properties.title = export_basename(report)
    document.core_properties.language = report.profile.target_lang
    return document


def _add_run(paragraph: Any, text: str, *, rtl: bool) -> Any:
    run = paragraph.add_run(text)  # python-docx turns "\n" into a line break
    if rtl:
        run.font.rtl = True
    return run


def bilingual_docx(report: Report, *, comments: bool = True) -> bytes:
    document = _new_document(report)
    src, tgt = report.profile.source_lang, report.profile.target_lang
    name = PurePosixPath(report.document.source_path.replace("\\", "/")).name
    document.add_heading(f"{name}: {src} → {tgt}", level=1)
    for notice in report.notices:
        document.add_paragraph().add_run(notice.explanation).italic = True
    table = document.add_table(rows=1, cols=3)
    table.style = "Table Grid"
    header = table.rows[0].cells
    header[0].text, header[1].text, header[2].text = "#", f"Source ({src})", f"Translation ({tgt})"
    source_rtl, target_rtl = is_rtl(src), is_rtl(tgt)
    for row in export_rows(report):
        cells = table.add_row().cells
        cells[0].text = str(row.number)
        _add_run(cells[1].paragraphs[0], row.source, rtl=source_rtl)
        run = _add_run(cells[2].paragraphs[0], row.span.text, rtl=target_rtl)
        if comments:
            for flag in row.open_flags:
                document.add_comment(
                    run,
                    text=f"{flag.code.value}: {flag.explanation}",
                    author=COMMENT_AUTHOR,
                    initials=COMMENT_INITIALS,
                )
    return _save(document)


def clean_docx(report: Report) -> bytes:
    document = _new_document(report)
    rtl = is_rtl(report.profile.target_lang)
    for item in translated_blocks(report):
        kind = item.block.kind
        if kind is BlockKind.BREAK:
            paragraph = document.add_paragraph()
            paragraph.alignment = WD_ALIGN_PARAGRAPH.CENTER
            _add_run(paragraph, BREAK_MARKER, rtl=rtl)  # keeps the paragraph's direction
            continue
        if kind is BlockKind.HEADING:
            paragraph = document.add_heading(level=1)
        elif kind is BlockKind.LIST_ITEM:
            paragraph = document.add_paragraph(style="List Bullet")
        else:
            paragraph = document.add_paragraph()
        run = _add_run(paragraph, item.text, rtl=rtl)
        if kind is BlockKind.FOOTNOTE:
            run.font.size = Pt(9)
    return _save(document)
```

```python
        path = self._path(key)
        tmp: str | None = None

            path.parent.mkdir(parents=True, exist_ok=True)
            fd, tmp = tempfile.mkstemp(dir=path.parent, suffix=".tmp")
```

```python
async def seed_run(
    db: Database,
    *,
    project: str = "demo",
    state: RunState = RunState.COMPLETE,
    target_lang: str = "en",
    filename: str = "story.txt",
    storage: Storage | None = None,
) -> SeededRun:
    cfg = CoglossaConfig.model_validate(SEED_CONFIG)
    profile = DocumentProfile(
        source_lang="fr",
        target_lang=target_lang,
        mixed_language=False,
        genre=Genre.LITERARY_PROSE,
        tone_register="neutral",
        word_count=8,
        pipeline_profile=PipelineProfile.STANDARD,
    )
    blocks, segments = _source(filename)
    now = datetime.now(UTC)
    finished = state in TERMINAL_STATES
    async with db.session() as s, s.begin():
        row = await runs.get_or_create_project(s, project)
        if row.target_lang is None:
            row.target_lang = target_lang
        document_id = uuid.uuid4()
        key = f"projects/{row.id}/documents/{document_id}/{filename}"
        if storage is not None:
            storage.put(key, SOURCE_TEXT.encode("utf-8"))
        doc = await runs.add_document(
            s,
            row.id,
            document_id=document_id,
            filename=filename,
            format=filename.rsplit(".", 1)[-1],
            sha256="0" * 64,
            storage_key=key,
        )
        await runs.save_source(s, doc.id, blocks, segments)
        run = await runs.create_run(
            s,
            doc.id,
            target_lang=target_lang,
            config_hash=config_hash(cfg),
            config_snapshot=cfg.model_dump(mode="json"),
            prompt_versions={},
        )
        await runs.save_chunks(s, run.id, [Chunk(id="c1", segment_ids=["s1", "s2", "s3", "s4"])])
        version = await runs.add_bible_version(
            s, row.id, BIBLE, status=runs.DRAFT, author=runs.ENGINE, source_run_id=run.id
        )
        for stage in ("ingest", "profile", "bible"):
            runs.finish_stage(await runs.begin_stage(s, run.id, stage), {})
        outcome = ChunkOutcome(
            chunk_id="c1",
            candidates=_candidates(),
            spans=_spans(),
            proposed_terms=[[], [GlossaryEntry(term="pluie", rendering="rain")], []],
        )
        await outputs.save_chunk_outcome(s, run.id, 0, outcome)
        for stage in ("translate", "reconcile", "score"):
            runs.finish_stage(await runs.begin_stage(s, run.id, stage, "c1"), {"errors": []})
        if finished:
            runs.finish_stage(await runs.begin_stage(s, run.id, "sweep"), {"errors": []})
        run.state = state.value
        run.profile = profile.model_dump(mode="json")
        run.language_tier = Reliability.B.value
        run.bible_version_id = version.id
        run.started_at = now
        run.finished_at = now if finished else None
        span_ids = list(
            await s.scalars(
                select(SpanRow.id).where(SpanRow.run_id == run.id).order_by(SpanRow.ordinal)
            )
        )
        flags = await s.execute(
            select(SpanRow.ordinal, FlagRow.code, FlagRow.id)
            .join(FlagRow, FlagRow.span_id == SpanRow.id)
            .where(SpanRow.run_id == run.id)
        )
        flag_ids = {f"p{ordinal + 1}:{code}": flag_id for ordinal, code, flag_id in flags}
        return SeededRun(
            project_id=row.id,
            document_id=doc.id,
            run_id=run.id,
            span_ids=span_ids,
            flag_ids=flag_ids,
            bible_version_id=version.id,
        )
```

```python
"""Data access for the review view (spec §8.4): statistics, span pages, flags, revisions and
the review_event feedback log (spec §6.5). Functions take an AsyncSession and never commit:
the caller owns the transaction."""

import uuid

from sqlalchemy import Select, exists, func, select
from sqlalchemy.ext.asyncio import AsyncSession

from coglossa.schema import FlagStatus, RevisionSource
from coglossa.schema.views import ReviewStats
from coglossa.store.models import FlagRow, RevisionRow, SpanRow, SpanScoreRow


def run_span_ids(run_id: uuid.UUID) -> Select[tuple[uuid.UUID]]:
    return select(SpanRow.id).where(SpanRow.run_id == run_id)


async def review_stats(s: AsyncSession, run_id: uuid.UUID) -> ReviewStats:
    spans = await s.scalar(select(func.count()).where(SpanRow.run_id == run_id))
    open_by_code = dict(
        (
            await s.execute(
                select(FlagRow.code, func.count())
                .where(
                    FlagRow.span_id.in_(run_span_ids(run_id)),
                    FlagRow.status == FlagStatus.OPEN.value,
                )
                .group_by(FlagRow.code)
            )
        ).all()
    )
    edited = await s.scalar(
        select(func.count(func.distinct(RevisionRow.span_id))).where(
            RevisionRow.span_id.in_(run_span_ids(run_id)),
            RevisionRow.source == RevisionSource.USER.value,
        )
    )
    return ReviewStats(
        spans=spans or 0,
        open_flags=sum(open_by_code.values()),
        flags_by_code=dict(sorted(open_by_code.items())),
        edited_spans=edited or 0,
    )


async def any_scored(s: AsyncSession, run_id: uuid.UUID) -> bool:
    """Whether any span has a meaning or style score (spec §6.2; the unscored notice)."""
    scored = exists().where(
        SpanScoreRow.span_id.in_(run_span_ids(run_id)),
        SpanScoreRow.meaning.is_not(None) | SpanScoreRow.style.is_not(None),
    )
    return bool(await s.scalar(select(scored)))
```

```python
def _projects_query() -> Select[tuple[Project, int, int, int | None]]:
    documents = (
        select(func.count(Document.id)).where(Document.project_id == Project.id).scalar_subquery()
    )
    run_count = (
        select(func.count(Run.id))
        .join(Document, Run.document_id == Document.id)
        .where(Document.project_id == Project.id)
        .scalar_subquery()
    )
    bible = (
        select(func.max(BibleVersion.version))
        .where(BibleVersion.project_id == Project.id)
        .scalar_subquery()
    )
    return select(Project, documents, run_count, bible)


def _project_info(project: Project, documents: int, run_count: int, bible: int | None) -> ProjectInfo:
    return ProjectInfo(
        id=str(project.id),
        name=project.name,
        target_lang=project.target_lang,
        source_lang=project.source_lang,
        pipeline_profile=PipelineProfile(project.pipeline_profile)
        if project.pipeline_profile
        else None,
        created_at=project.created_at,
        documents=documents,
        runs=run_count,
        bible_version=bible,
    )


async def create_project(
    db: Database,
    name: str,
    *,
    target_lang: str,
    source_lang: str | None = None,
    pipeline_profile: PipelineProfile | None = None,
) -> ProjectInfo:
    name = name.strip()
    if not name:
        raise service.InvalidRequestError("a project needs a name")
    if len(name) > MAX_PROJECT_NAME:
        raise service.InvalidRequestError(
            f"project names are at most {MAX_PROJECT_NAME} characters"
        )
    project = Project(
        name=name,
        target_lang=target_lang,
        source_lang=source_lang,
        pipeline_profile=pipeline_profile.value if pipeline_profile else None,
    )
    try:
        async with db.session() as s, s.begin():
            s.add(project)
            await s.flush()
    except IntegrityError as e:  # the name is unique
        raise service.ConflictError(f"a project named '{name}' already exists") from e
    return await get_project(db, project.id)


async def list_projects(db: Database) -> list[ProjectInfo]:
```

  - `outputs` (M3)

  - `coglossa.catalog`:
    - `bible_view(row: BibleVersion) -> BibleView`
    - `bible_versions(db, project_id) -> list[BibleVersionInfo]` (newest first)
    - `project_bible(db, project_id, version: int | None = None) -> BibleView`

    - `save_project_bible(db, project_id, bible: Bible, *, base_version: int | None) -> BibleView`

**Rules:**
- **`save_project_bible`** locks the project row, then compares `base_version` with the project's latest version number (`None` when it has none). A mismatch raises:

  ```
  ConflictError("the bible changed since you opened it (now version <n|none>, you edited version <m|none>); reload it and apply your changes again")
  ```

  The new version is `approved`, authored by `user`, with no source run.
- **`rerun_sweep`** (spec §8.3, "editing a locked term after translation offers to re-run the sweep"):
  - **Refused for a run that is not finished:** a run not `complete`/`complete_with_errors` raises `InvalidRunStateError("run <id> is <state>; the sweep can be re-run once the run is complete")`.
  - **Refused when the sweep is off:** if the run's own config snapshot turns the sweep off for its profile, it raises `InvalidRunStateError("the sweep is off for <profile> documents (profiles.sweep in the config)")`.
  - **Otherwise, under the run lock:**
    - point the run at the project's latest **approved** version (keep its own when there is none)
    - delete the `sweep` stage row
    - set the state to `sweeping`, `finished_at = None`, `cancel_requested = False`
    - after commit, queue `finish_run`
  - **Earlier sweep revisions are kept:** the new sweep works on the current text, user edits included. Its changes append to the history.
  - **Returns:** `"re-running the sweep with bible version <n>"`.

```python
    async with db.session() as s:
        run = await runs.get_run(s, run_id)
        if run.bible_version_id is None:
            raise service.InvalidRunStateError(
                f"the bible is not ready yet; run {run_id} is {run.state}"
            )
        return bible_view(await runs.get_bible_version(s, run.bible_version_id))


async def save_project_bible(
    db: Database, project_id: uuid.UUID, bible: Bible, *, base_version: int | None
) -> BibleView:
    """A person's edit of the project bible: a new approved version. `base_version` is the
    version the edit started from; a newer save in between refuses this one."""
    async with db.session() as s, s.begin():
        await runs.lock_project(s, project_id)
        latest = await runs.latest_bible(s, project_id, approved_only=False)
        current = latest.version if latest else None
        if base_version != current:
            raise service.ConflictError(
                f"the bible changed since you opened it (now version {current or 'none'}, you "
                f"edited version {base_version or 'none'}); reload it and apply your changes again"
            )
        row = await runs.add_bible_version(
            s, project_id, bible, status=runs.APPROVED, author=runs.USER
        )
        return bible_view(row)
```

```python
async def rerun_sweep(db: Database, queue: JobQueue, run_id: uuid.UUID) -> str:
    """Spec §8.3: after a locked bible entry changes, re-run the consistency sweep of a
    finished run with the project's latest approved bible. Earlier revisions stay: the new
    sweep works on the current text, reviewers' edits included."""
    async with db.session() as s, s.begin():
        run = await runs.get_run(s, run_id, lock=True)
        state = RunState(run.state)
        if state not in (RunState.COMPLETE, RunState.COMPLETE_WITH_ERRORS):
            raise InvalidRunStateError(
                f"run {run_id} is {state}; the sweep can be re-run once the run is complete"
            )
        profile = DocumentProfile.model_validate(run.profile).pipeline_profile
        snapshot = CoglossaConfig.model_validate(run.config_snapshot)
        if not snapshot.profiles.sweep.get(profile, True):
            raise InvalidRunStateError(
                f"the sweep is off for {profile} documents (profiles.sweep in the config)"
            )
        doc = await runs.get_document(s, run.document_id)
        approved = await runs.latest_bible(s, doc.project_id, approved_only=True)
        if approved is not None:
            run.bible_version_id = approved.id
        version = (await runs.get_bible_version(s, run.bible_version_id)).version
        await runs.delete_stages(s, run_id, stages=["sweep"])
        run.state, run.finished_at, run.cancel_requested = RunState.SWEEPING, None, False
    await _queue_run_job(queue, TASK_FINISH_RUN, run_id)
    return f"re-running the sweep with bible version {version}"
```

A finished run always has a bible version, so `run.bible_version_id` is set here. `profile` is a `PipelineProfile` (a `StrEnum`), so the f-string prints `short`.

**Rules:**
- **Filters:**
  - `flagged=True` means the span has at least one **open** flag; `False` means it has none.
  - `code` means the span has an **open** flag with that code.
  - Score bounds are inclusive. A span with a `null` score never matches a bound on that score.
- **Order:** spans come in reading order. `number` is the position among **all** the run's spans, not among the filtered ones.
- **Text and source:** `text` is the latest revision. `source` is the span's segments joined with a single space, as the report's exports do.
- **Detail:**
  - `candidates` are the chunk's candidates whose segment range overlaps the span's, in stored order.
  - `revisions` are oldest first.
- **Paging:** `offset < 0`, `limit < 1` or `limit > 500` raises `InvalidRequestError("offset must be ≥ 0 and limit between 1 and 500")`.
- **Missing rows:**
  - an unknown run: `NotFoundError("run <id> not found")`
  - a span not in this run: `NotFoundError("span <id> not found in run <run>")`
- **Segment ids** are `s<n>` in reading order (M1's segmenter), so a span's segment ids are `s<start>…s<end>`.

```python
_SEGMENT_ID = re.compile(r"^s(\d+)$")


def segment_number(segment_id: str) -> int:
    """Segment ids are s1, s2, … in reading order (M1's segmenter)."""
    match = _SEGMENT_ID.match(segment_id)
    if match is None:
        raise ValueError(f"{segment_id!r} is not a segment id")
    return int(match.group(1))


def segment_range(start: str, end: str) -> list[str]:
    return [f"s{n}" for n in range(segment_number(start), segment_number(end) + 1)]


@dataclass(frozen=True)
class SpanFilter:
    flagged: bool | None = None  # True: has an open flag; False: has none
    code: FlagCode | None = None  # has an open flag with this code
    min_meaning: float | None = None  # bounds are inclusive; null scores never match
    max_meaning: float | None = None
    min_style: float | None = None
    max_style: float | None = None


def _has_open_flag(code: FlagCode | None = None) -> ColumnElement[bool]:
    condition = exists().where(
        FlagRow.span_id == SpanRow.id, FlagRow.status == FlagStatus.OPEN.value
    )
    if code is not None:
        condition = condition.where(FlagRow.code == code.value)
    return condition


def _conditions(f: SpanFilter) -> list[ColumnElement[bool]]:
    conditions: list[ColumnElement[bool]] = []
    if f.flagged is not None:
        conditions.append(_has_open_flag() if f.flagged else ~_has_open_flag())
    if f.code is not None:
        conditions.append(_has_open_flag(f.code))
    if f.min_meaning is not None:
        conditions.append(SpanScoreRow.meaning >= f.min_meaning)
    if f.max_meaning is not None:
        conditions.append(SpanScoreRow.meaning <= f.max_meaning)
    if f.min_style is not None:
        conditions.append(SpanScoreRow.style >= f.min_style)
    if f.max_style is not None:
        conditions.append(SpanScoreRow.style <= f.max_style)
    return conditions


@dataclass(frozen=True)
class SpanRecord:
    number: int  # 1-based position among all of the run's spans
    span: SpanRow
    score: SpanScoreRow


async def span_records(
    s: AsyncSession, run_id: uuid.UUID, f: SpanFilter, *, offset: int, limit: int
) -> tuple[int, list[SpanRecord]]:
    conditions = _conditions(f)
    numbered = (
        select(
            SpanRow.id.label("span_id"),
            func.row_number()
            .over(order_by=(SpanRow.chunk_ordinal, SpanRow.ordinal))
            .label("number"),
        )
        .where(SpanRow.run_id == run_id)
        .subquery()
    )
    total = await s.scalar(
        select(func.count())
        .select_from(SpanRow)
        .join(SpanScoreRow, SpanScoreRow.span_id == SpanRow.id)
        .where(SpanRow.run_id == run_id, *conditions)
    )
    rows = await s.execute(
        select(numbered.c.number, SpanRow, SpanScoreRow)
        .join(numbered, numbered.c.span_id == SpanRow.id)
        .join(SpanScoreRow, SpanScoreRow.span_id == SpanRow.id)
        .where(*conditions)
        .order_by(numbered.c.number)
        .offset(offset)
        .limit(limit)
    )
    return total or 0, [SpanRecord(number, span, score) for number, span, score in rows.all()]


async def span_record(s: AsyncSession, run_id: uuid.UUID, span_id: uuid.UUID) -> SpanRecord:
    row = (
        await s.execute(
            select(SpanRow, SpanScoreRow)
            .join(SpanScoreRow, SpanScoreRow.span_id == SpanRow.id)
            .where(SpanRow.id == span_id, SpanRow.run_id == run_id)
        )
    ).one_or_none()
    if row is None:
        raise NotFoundError(f"span {span_id} not found in run {run_id}")
    span, score = row
    number = await s.scalar(
        select(func.count()).where(
            SpanRow.run_id == run_id,
            tuple_(SpanRow.chunk_ordinal, SpanRow.ordinal) <= (span.chunk_ordinal, span.ordinal),
        )
    )
    return SpanRecord(number or 0, span, score)


async def flags_of(
    s: AsyncSession, span_ids: Sequence[uuid.UUID]
) -> dict[uuid.UUID, list[FlagRow]]:
    flags: dict[uuid.UUID, list[FlagRow]] = defaultdict(list)
    for flag in await s.scalars(
        select(FlagRow).where(FlagRow.span_id.in_(span_ids)).order_by(FlagRow.id)
    ):
        flags[flag.span_id].append(flag)
    return flags


async def latest_texts(s: AsyncSession, span_ids: Sequence[uuid.UUID]) -> dict[uuid.UUID, str]:
    newest = (
        select(func.max(RevisionRow.id))
        .where(RevisionRow.span_id.in_(span_ids))
        .group_by(RevisionRow.span_id)
    )
    rows = await s.execute(
        select(RevisionRow.span_id, RevisionRow.after).where(RevisionRow.id.in_(newest))
    )
    return dict(rows.all())


async def edited_spans(s: AsyncSession, span_ids: Sequence[uuid.UUID]) -> set[uuid.UUID]:
    rows = await s.scalars(
        select(RevisionRow.span_id)
        .where(
            RevisionRow.span_id.in_(span_ids), RevisionRow.source == RevisionSource.USER.value
        )
        .distinct()
    )
    return set(rows)


async def segment_texts(
    s: AsyncSession, document_id: uuid.UUID, segment_ids: Collection[str]
) -> dict[str, str]:
    rows = await s.execute(
        select(SegmentRow.segment_id, SegmentRow.text).where(
            SegmentRow.document_id == document_id, SegmentRow.segment_id.in_(list(segment_ids))
        )
    )
    return dict(rows.all())


async def chunk_candidates(
    s: AsyncSession, run_id: uuid.UUID, chunk_id: str
) -> list[CandidateRow]:
    rows = await s.scalars(
        select(CandidateRow)
        .where(CandidateRow.run_id == run_id, CandidateRow.chunk_id == chunk_id)
        .order_by(CandidateRow.id)
    )
    return list(rows)


async def revisions_of(s: AsyncSession, span_id: uuid.UUID) -> list[RevisionRow]:
    rows = await s.scalars(
        select(RevisionRow).where(RevisionRow.span_id == span_id).order_by(RevisionRow.id)
    )
    return list(rows)
```

```python
async def _review_spans(

    db: Database,
    run_id: uuid.UUID,
    filt: SpanFilter | None = None,
    *,
    offset: int = 0,
    limit: int = 100,
) -> SpanPage:

def _overlaps(candidate: CandidateRow, span: SpanRow) -> bool:
    return segment_number(candidate.seg_start) <= segment_number(
        span.seg_end
    ) and segment_number(candidate.seg_end) >= segment_number(span.seg_start)


async def _detail(s: AsyncSession, run_id: uuid.UUID, span_id: uuid.UUID) -> SpanDetail:

    (base,) = await _review_spans(s, run.document_id, [record])
    span = record.span
    candidates = [
        Candidate(
            chunk_id=c.chunk_id,
            translator=c.translator,
            model=c.model,
            start=c.seg_start,
            end=c.seg_end,
            text=c.text,
            notes=c.notes,

    )
```

- Produces:
  - `coglossa.review`, each action taking `*, user: str | None = None`:
    - `edit_span(db, run_id, span_id, text: str, *, reason: str | None = None, user=None) -> SpanDetail`
    - `use_candidate(db, run_id, span_id, translator: str, *, user=None) -> SpanDetail`
    - `accept_span(db, run_id, span_id, *, user=None) -> SpanDetail`
    - `set_flag_status(db, run_id, flag_id: int, status: FlagStatus, *, reason: str | None = None, user=None) -> SpanDetail`
    - `add_bible_entry(db, run_id, span_id, entry: GlossaryEntry | Entity, *, user=None) -> BibleView`

    - `add_revision(s, span_id, *, before, after, reason) -> None`
    - `add_event(s, run_id, span_id, action: ReviewAction, payload: dict) -> None`
    - `set_open_flags(s, span_id, status) -> list[int]`
    - `get_flag(s, run_id, flag_id) -> FlagRow`

**Rules:**
- **Every action:**
  - It runs in one transaction that first takes the run lock.
  - It is refused while the run is `sweeping`: `InvalidRunStateError("run <id> is running its consistency sweep; try again when it finishes")`.
  - Its event payload always has `"user"` (the name or `null`).
- **`edit_span`:**
  - Blank text raises `InvalidRequestError("the translation must not be empty")`.
  - Text equal to the current text writes nothing.
  - Otherwise it writes a user revision with the given reason (default `"edited by a reviewer"`) and an `edit` event with `{user, before, after, reason}`.
- **`use_candidate`:**
  - The translator's candidate pieces that overlap the span must tile it exactly: the first starts at the span's start, the last ends at its end, with no gap or overlap between pieces.
  - No overlapping piece raises `InvalidRequestError("no '<translator>' candidate covers this passage")`.
  - Pieces that do not tile raise `ConflictError("the '<translator>' candidate's passage boundaries differ from this passage (<start>–<end>); copy its text and edit instead")`.
  - The text is the pieces' texts, stripped and joined with one space.
  - A revision (reason `"used the <translator> candidate"`) is written only when the text changes. A `use_candidate` event with `{user, translator, before, after}` is **always** written: picking the current text is feedback too.
- **`accept_span`:** sets every **open** flag on the span to `accepted` and writes an `accept` event with `{user, flags: [ids]}`. The event is written even with no open flags.
- **`set_flag_status`:**
  - `status` is `accepted`, `dismissed` or `open`. `resolved` raises `InvalidRequestError("only the sweep resolves flags; use accepted, dismissed or open")`.
  - Dismissing needs a non-blank reason: `InvalidRequestError("dismissing a flag needs a reason")`. `dismiss_reason` is kept only while dismissed.
  - A flag of another run raises `NotFoundError("flag <id> not found in run <run>")`.
  - Event actions: `accept_flag`, `dismiss_flag`, `reopen_flag`, with payload `{user, flag, code, before, reason}`.
- **`add_bible_entry`:**
  - The entry is a `GlossaryEntry` or an `Entity`. Its term or name and its rendering are trimmed and must not be blank; otherwise `InvalidRequestError("a bible entry needs a term or name and a rendering")`.
  - **Base:** it locks the project and builds on the project's latest version. With no version it raises `InvalidRunStateError("the project has no bible yet; wait for the run to build one")`.
  - **Merge:** an existing glossary term (case-insensitive, trimmed) or entity name is replaced, otherwise the entry is appended.
  - **Result:** a new `approved` version authored by `user` with `source_run_id` = the run, and an `add_to_bible` event with `{user, kind: "glossary"|"entity", entry, version}`.
  - It does not change the run's own bible version: re-running the sweep (Task 9) applies new locked entries.

```python
async def _writable(s: AsyncSession, run_id: uuid.UUID) -> Run:
    run = await runs.get_run(s, run_id, lock=True)
    if run.state == RunState.SWEEPING:
        raise service.InvalidRunStateError(
            f"run {run_id} is running its consistency sweep; try again when it finishes"
        )
    return run


def _payload(user: str | None, **data: Any) -> dict[str, Any]:
    return {"user": user, **data}


async def _current_text(s: AsyncSession, span_id: uuid.UUID) -> str:
    return (await review_store.latest_texts(s, [span_id]))[span_id]


async def edit_span(
    db: Database,
    run_id: uuid.UUID,
    span_id: uuid.UUID,
    text: str,
    *,
    reason: str | None = None,
    user: str | None = None,
) -> SpanDetail:
    if not text.strip():
        raise service.InvalidRequestError("the translation must not be empty")
    async with db.session() as s, s.begin():
        await _writable(s, run_id)
        await review_store.span_record(s, run_id, span_id)
        current = await _current_text(s, span_id)
        if text != current:
            note = (reason or "").strip() or "edited by a reviewer"
            await review_store.add_revision(s, span_id, before=current, after=text, reason=note)
            await review_store.add_event(
                s,
                run_id,
                span_id,
                ReviewAction.EDIT,
                _payload(user, before=current, after=text, reason=note),
            )
        return await _detail(s, run_id, span_id)


def _tiles(pieces: list[CandidateRow], span: SpanRow) -> bool:
    if pieces[0].seg_start != span.seg_start or pieces[-1].seg_end != span.seg_end:
        return False
    return all(
        segment_number(nxt.seg_start) == segment_number(prev.seg_end) + 1
        for prev, nxt in zip(pieces, pieces[1:], strict=False)
    )


async def use_candidate(
    db: Database,
    run_id: uuid.UUID,
    span_id: uuid.UUID,
    translator: str,
    *,
    user: str | None = None,
) -> SpanDetail:
    async with db.session() as s, s.begin():
        await _writable(s, run_id)
        span = (await review_store.span_record(s, run_id, span_id)).span
        pieces = sorted(
            (
                c
                for c in await review_store.chunk_candidates(s, run_id, span.chunk_id)
                if c.translator == translator and _overlaps(c, span)
            ),
            key=lambda c: segment_number(c.seg_start),
        )
        if not pieces:
            raise service.InvalidRequestError(f"no '{translator}' candidate covers this passage")
        if not _tiles(pieces, span):
            raise service.ConflictError(
                f"the '{translator}' candidate's passage boundaries differ from this passage "
                f"({span.seg_start}–{span.seg_end}); copy its text and edit instead"
            )
        text = " ".join(p.text.strip() for p in pieces)
        current = await _current_text(s, span_id)
        if text != current:
            await review_store.add_revision(
                s, span_id, before=current, after=text, reason=f"used the {translator} candidate"
            )
        await review_store.add_event(
            s,
            run_id,
            span_id,
            ReviewAction.USE_CANDIDATE,
            _payload(user, translator=translator, before=current, after=text),
        )
        return await _detail(s, run_id, span_id)


async def accept_span(
    db: Database, run_id: uuid.UUID, span_id: uuid.UUID, *, user: str | None = None
) -> SpanDetail:
    async with db.session() as s, s.begin():
        await _writable(s, run_id)
        await review_store.span_record(s, run_id, span_id)
        accepted = await review_store.set_open_flags(s, span_id, FlagStatus.ACCEPTED)
        await review_store.add_event(
            s, run_id, span_id, ReviewAction.ACCEPT, _payload(user, flags=accepted)
        )
        return await _detail(s, run_id, span_id)


_FLAG_ACTIONS = {
    FlagStatus.ACCEPTED: ReviewAction.ACCEPT_FLAG,
    FlagStatus.DISMISSED: ReviewAction.DISMISS_FLAG,
    FlagStatus.OPEN: ReviewAction.REOPEN_FLAG,
}


async def set_flag_status(
    db: Database,
    run_id: uuid.UUID,
    flag_id: int,
    status: FlagStatus,
    *,
    reason: str | None = None,
    user: str | None = None,
) -> SpanDetail:
    if status not in _FLAG_ACTIONS:
        raise service.InvalidRequestError(
            "only the sweep resolves flags; use accepted, dismissed or open"
        )
    reason = (reason or "").strip() or None
    if status is FlagStatus.DISMISSED and reason is None:
        raise service.InvalidRequestError("dismissing a flag needs a reason")
    async with db.session() as s, s.begin():
        await _writable(s, run_id)
        flag = await review_store.get_flag(s, run_id, flag_id)
        before = flag.status
        flag.status = status.value
        flag.dismiss_reason = reason if status is FlagStatus.DISMISSED else None
        await review_store.add_event(
            s,
            run_id,
            flag.span_id,
            _FLAG_ACTIONS[status],
            _payload(user, flag=flag_id, code=flag.code, before=before, reason=reason),
        )
        return await _detail(s, run_id, flag.span_id)


def _key(text: str) -> str:
    return text.strip().casefold()


def _with_entry(bible: Bible, entry: GlossaryEntry | Entity) -> Bible:
    """The bible with `entry` replacing the entry of the same term or name, or appended."""
    if isinstance(entry, GlossaryEntry):
        replaced = any(_key(g.term) == _key(entry.term) for g in bible.glossary)
        kept = [entry if _key(g.term) == _key(entry.term) else g for g in bible.glossary]
        glossary = kept if replaced else [*bible.glossary, entry]
        return bible.model_copy(update={"glossary": glossary})
    replaced = any(_key(e.name) == _key(entry.name) for e in bible.entities)
    kept_entities = [entry if _key(e.name) == _key(entry.name) else e for e in bible.entities]
    entities = kept_entities if replaced else [*bible.entities, entry]
    return bible.model_copy(update={"entities": entities})


def _trimmed(entry: GlossaryEntry | Entity) -> GlossaryEntry | Entity:
    if isinstance(entry, GlossaryEntry):
        return entry.model_copy(update={"term": entry.term.strip(), "rendering": entry.rendering.strip()})
    return entry.model_copy(update={"name": entry.name.strip(), "rendering": entry.rendering.strip()})


async def add_bible_entry(
    db: Database,
    run_id: uuid.UUID,
    span_id: uuid.UUID,
    entry: GlossaryEntry | Entity,
    *,
    user: str | None = None,
) -> BibleView:
    """Spec §8.4 "add to bible": the entry joins the project's bible as a new approved
    version. The run keeps the version it was translated with; re-running the sweep applies
    new locked entries to it."""
    entry = _trimmed(entry)
    name = entry.term if isinstance(entry, GlossaryEntry) else entry.name
    if not name or not entry.rendering:
        raise service.InvalidRequestError("a bible entry needs a term or name and a rendering")
    async with db.session() as s, s.begin():
        run = await _writable(s, run_id)
        await review_store.span_record(s, run_id, span_id)
        doc = await runs.get_document(s, run.document_id)
        await runs.lock_project(s, doc.project_id)
        base = await runs.latest_bible(s, doc.project_id, approved_only=False)
        if base is None:
            raise service.InvalidRunStateError(
                "the project has no bible yet; wait for the run to build one"
            )
        bible = _with_entry(Bible.model_validate(base.content), entry)
        row = await runs.add_bible_version(
            s, doc.project_id, bible, status=runs.APPROVED, author=runs.USER, source_run_id=run_id
        )
        kind = "glossary" if isinstance(entry, GlossaryEntry) else "entity"
        await review_store.add_event(
            s,
            run_id,
            span_id,
            ReviewAction.ADD_TO_BIBLE,
            _payload(user, kind=kind, entry=entry.model_dump(mode="json"), version=row.version),
        )
        return bible_view(row)
```

```python
    tables = [t.name for t in Base.metadata.sorted_tables] + list(PROCRASTINATE_TABLES)
    async with db.engine.begin() as conn:
```

```python
"""Spec §3 `auth`: `none`, or `trusted_header` behind a reverse proxy that authenticates
people and passes the user name in a header. The name goes into the feedback log."""

from typing import Annotated

from fastapi import Depends, HTTPException, Request

from coglossa_api.context import get_context


def current_user(request: Request) -> str | None:
    auth = get_context(request).cfg.auth
    if auth.mode == "none":
        return None
    user = (request.headers.get(auth.header) or "").strip()
    if not user:
        raise HTTPException(
            status_code=401,
            detail=f"missing {auth.header} header: sign in through the proxy in front of Coglossa",
        )
    return user


User = Annotated[str | None, Depends(current_user)]
```

Create `api/coglossa_api/errors.py`:

```python
"""Exceptions to HTTP responses. The body is always {"detail": "<one line>"}: never a
traceback, a database URL or a password. Unexpected errors are logged with their traceback
and answered with "internal error"."""

import logging
from collections.abc import Awaitable, Callable

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from sqlalchemy.exc import InterfaceError, OperationalError

from coglossa.config import ConfigError
from coglossa.ingest.base import IngestError
from coglossa.service import ConflictError, InvalidRequestError
from coglossa.storage import StorageError
from coglossa.store.db import error_reason
from coglossa.store.runs import NotFoundError

log = logging.getLogger("coglossa.api")
Handler = Callable[[Request, Exception], Awaitable[JSONResponse]]


class UploadTooLargeError(Exception):
    """The upload is larger than api.max_upload_mb (HTTP 413)."""


_STATUS: tuple[tuple[type[Exception], int], ...] = (
    (NotFoundError, 404),
    (ConflictError, 409),  # includes InvalidRunStateError
    (UploadTooLargeError, 413),
    (InvalidRequestError, 422),
    (IngestError, 422),
    (ConfigError, 500),
    (StorageError, 500),
)


def _response(status: int, message: str) -> JSONResponse:
    return JSONResponse(status_code=status, content={"detail": " ".join(message.split())})


def _handler(status: int) -> Handler:
    async def handle(request: Request, exc: Exception) -> JSONResponse:
        return _response(status, str(exc))

    return handle


async def _database_down(request: Request, exc: Exception) -> JSONResponse:
    reason = error_reason(exc)
    log.warning("database unavailable: %s", reason)
    return _response(503, f"the database is unavailable: {reason}")


async def _internal(request: Request, exc: Exception) -> JSONResponse:
    log.error("internal error on %s %s", request.method, request.url.path, exc_info=exc)
    return _response(500, "internal error")


def install_error_handlers(app: FastAPI) -> None:
    for exc_type, status in _STATUS:
        app.add_exception_handler(exc_type, _handler(status))
    app.add_exception_handler(OperationalError, _database_down)
    app.add_exception_handler(InterfaceError, _database_down)
    app.add_exception_handler(Exception, _internal)
```

```python
"""The REST API (spec §2.1, §8): a thin HTTP layer over the control plane (coglossa.service,
coglossa.catalog, coglossa.review). It never calls a model; doctor, which checks the
backends, is the one exception."""

import contextlib
from collections.abc import AsyncIterator, Callable
from contextlib import AbstractAsyncContextManager
from pathlib import Path

from fastapi import APIRouter, Depends, FastAPI

import coglossa
from coglossa.config import CoglossaConfig
from coglossa.prompts.library import PromptLibrary
from coglossa.service import JobQueue
from coglossa.storage import build_storage
from coglossa.store.db import Database, database_url
from coglossa.worker.app import ProcrastinateQueue, open_app
from coglossa_api.auth import current_user
from coglossa_api.context import ApiContext
from coglossa_api.errors import install_error_handlers
from coglossa_api.routes import ROUTERS

QueueOpener = Callable[[str], AbstractAsyncContextManager[JobQueue]]


@contextlib.asynccontextmanager
async def procrastinate_queue(url: str) -> AsyncIterator[JobQueue]:
    """The job queue. open_app swaps the connector of procrastinate's shared app, so a process
    opens it once, here for the app's lifetime; any other opening (a worker in the same
    process, in tests) nests inside this one and is closed first."""
    async with open_app(url) as opened:
        yield ProcrastinateQueue(opened)


health = APIRouter(prefix="/api", tags=["system"])


@health.get("/health")
async def get_health() -> dict[str, str]:
    """Liveness: answers without the database and without a signed-in user."""
    return {"status": "ok", "version": coglossa.__version__}


def create_app(
    cfg: CoglossaConfig, config_path: Path, *, open_queue: QueueOpener = procrastinate_queue
) -> FastAPI:
    @contextlib.asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        db = Database(database_url(cfg))
        try:
            async with open_queue(db.url) as queue:
                app.state.ctx = ApiContext(
                    cfg=cfg,
                    config_path=config_path,
                    db=db,
                    storage=build_storage(cfg.storage),
                    prompts=PromptLibrary(cfg.prompts_dir),
                    queue=queue,
                )
                yield
        finally:
            await db.dispose()

    app = FastAPI(
        title="Coglossa",
        version=coglossa.__version__,
        summary="Multi-agent translation with verifiable, scored output.",
        lifespan=lifespan,
    )
    install_error_handlers(app)
    app.include_router(health)
    protected = APIRouter(prefix="/api", dependencies=[Depends(current_user)])
    for router in ROUTERS:
        protected.include_router(router)
    app.include_router(protected)
    return app
```

```python
"""`coglossa-api`: serve the REST API. It refuses to start, with one line, on an invalid
config, prompts that do not render, an unreachable or unmigrated database, or a storage path
it cannot write (spec §7.3)."""

import argparse
import sys
from pathlib import Path

import uvicorn

from coglossa.config import ConfigError, load_config
from coglossa.logs import configure_json_logging, remove_json_logging
from coglossa.prompts.check import validate_prompts
from coglossa.prompts.library import PromptLibrary
from coglossa.storage import StorageError, build_storage
from coglossa.store.db import database_url
from coglossa.store.migrate import ensure_migrated
from coglossa_api.app import create_app

EXIT_OK, EXIT_FAILED = 0, 1


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="coglossa-api", description="Serve the Coglossa REST API.")
    parser.add_argument("--config", type=Path, default=Path("coglossa.yaml"))
    parser.add_argument("--host", default="127.0.0.1", help="use 0.0.0.0 inside a container")
    parser.add_argument("--port", type=int, default=8080)
    args = parser.parse_args(argv)
    try:
        cfg, warnings = load_config(args.config)
        for warning in warnings:
            print(f"warning: {warning.message}", file=sys.stderr)
        validate_prompts(cfg, PromptLibrary(cfg.prompts_dir))
        ensure_migrated(database_url(cfg))
        build_storage(cfg.storage).check_writable()
    except (ConfigError, StorageError) as e:
        print(f"error: {e}", file=sys.stderr)
        return EXIT_FAILED
    handler = configure_json_logging()
    try:
        uvicorn.run(create_app(cfg, args.config.resolve()), host=args.host, port=args.port)
    finally:
        remove_json_logging(handler)
    return EXIT_OK
```

| `GET /projects/{project_id}/bible/versions` | | `list[BibleVersionInfo]` |
| `PUT /projects/{project_id}/bible` | `SaveBible` | `BibleView` |

**Upload rules:**
- **Defaults:** the form's `target_lang`, `source_lang` and `pipeline_profile` default to the project's. Without any target language the upload is refused (422, `"choose a target language: project '<name>' has no default"`).
- **Size:** the body is read in 1 MiB pieces and refused with 413 past `api.max_upload_mb`: `"<name> is larger than the <n> MB upload limit (api.max_upload_mb)"`. Starlette has already spooled the multipart body by then; a proxy limit in front is the outer guard, noted in `docs/m4a-followups.md`.
- **Language codes:** they are validated with `LANGUAGE_CODE_PATTERN` (422).

**Action messages:**
- cancel: `"cancelled"`, or `"cancel requested; running work stops after the current chunk or stage"`
- retry and sweep: the message the service returns
- approve: `"bible version <n> approved; translation queued"`

```python
@router.delete("/projects/{project_id}", status_code=204)
async def delete_project(
    project_id: uuid.UUID, ctx: Ctx, confirm: Annotated[str, Query()] = ""
) -> Response:
    """Deletes every document, run, stored file and model-call payload of the project
    (spec §5). `confirm` must repeat the project's name."""
    project = await catalog.get_project(ctx.db, project_id)
    if confirm != project.name:
        raise service.InvalidRequestError(
            f"to delete project '{project.name}', pass confirm={project.name}"
        )
    await service.delete_project_id(ctx.db, ctx.storage, project_id)
    return Response(status_code=204)


@router.get("/projects/{project_id}/documents")
async def list_documents(project_id: uuid.UUID, ctx: Ctx) -> list[DocumentSummary]:
    return await catalog.list_documents(ctx.db, project_id)


async def read_upload(file: UploadFile, max_mb: int) -> bytes:
    limit = max_mb * _PIECE
    pieces: list[bytes] = []
    size = 0
    while piece := await file.read(_PIECE):
        size += len(piece)
        if size > limit:
            name = display_name(file.filename or "") or "the upload"
            raise UploadTooLargeError(
                f"{name} is larger than the {max_mb} MB upload limit (api.max_upload_mb)"
            )
        pieces.append(piece)
    return b"".join(pieces)


@router.post("/projects/{project_id}/runs", status_code=202)
async def upload(
    project_id: uuid.UUID,
    file: UploadFile,
    ctx: Ctx,
    target_lang: LanguageField = None,
    source_lang: LanguageField = None,
    pipeline_profile: Annotated[PipelineProfile | None, Form()] = None,
    checkpoint: Annotated[bool | None, Form()] = None,
    use_project_bible: Annotated[bool, Form()] = False,
) -> RunSummary:
    """Upload a document and queue a run. Form fields left out take the project's defaults."""
    project = await catalog.get_project(ctx.db, project_id)
    target = target_lang or project.target_lang
    if target is None:
        raise service.InvalidRequestError(
            f"choose a target language: project '{project.name}' has no default"
        )
    data = await read_upload(file, ctx.cfg.api.max_upload_mb)
    opts = service.RunOptions(
        target_lang=target,
        source_lang=source_lang or project.source_lang,
        pipeline_profile=pipeline_profile or project.pipeline_profile,
        checkpoint=checkpoint,
        use_project_bible=use_project_bible,
    )
    run_id = await service.submit_bytes(
        ctx.db,
        ctx.storage,
        ctx.queue,
        ctx.cfg,
        ctx.prompts,
        file.filename or "",
        data,
        opts,
        project=project_id,
    )
    return (await catalog.run_detail(ctx.db, run_id)).run
```

```python
"""The canonical report and its exports (spec §7.5): HTML, a clean DOCX, a bilingual DOCX
with flags as comments, and the report as a JSON download. All of them show the current
revisions."""

import asyncio
import re
import uuid
from enum import StrEnum
from urllib.parse import quote

from fastapi import APIRouter, Response

from coglossa import service
from coglossa.export.docx import bilingual_docx, clean_docx
from coglossa.export.html import render_html
from coglossa.export.rows import export_basename
from coglossa.schema import Report
from coglossa_api.context import Ctx

router = APIRouter(tags=["exports"])
DOCX = "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
_UNSAFE = re.compile(r"[^A-Za-z0-9._ -]")


class ExportKind(StrEnum):
    HTML = "html"
    DOCX = "docx"
    BILINGUAL_DOCX = "bilingual-docx"
    JSON = "json"


def content_disposition(filename: str) -> str:
    """RFC 6266/5987: an ASCII fallback and the exact UTF-8 name."""
    fallback = _UNSAFE.sub("_", filename) or "download"
    return f"attachment; filename=\"{fallback}\"; filename*=UTF-8''{quote(filename, safe='')}"


@router.get("/runs/{run_id}/report")
async def get_report(run_id: uuid.UUID, ctx: Ctx) -> Report:
    return await service.build_report(ctx.db, run_id)


@router.get(
    "/runs/{run_id}/exports/{kind}",
    response_class=Response,
    responses={200: {"content": {"text/html": {}, DOCX: {}, "application/json": {}}}},
)
async def export(run_id: uuid.UUID, kind: ExportKind, ctx: Ctx, comments: bool = True) -> Response:
    report = await service.build_report(
        ctx.db, run_id, include_llm_calls=kind is ExportKind.JSON
    )
    base = export_basename(report)
    if kind is ExportKind.HTML:
        body: bytes = (await asyncio.to_thread(render_html, report)).encode("utf-8")
        filename, media_type = f"{base}.html", "text/html; charset=utf-8"
    elif kind is ExportKind.DOCX:
        body = await asyncio.to_thread(clean_docx, report)
        filename, media_type = f"{base}.docx", DOCX
    elif kind is ExportKind.BILINGUAL_DOCX:
        body = await asyncio.to_thread(bilingual_docx, report, comments=comments)
        filename, media_type = f"{base}.bilingual.docx", DOCX
    else:
        body = report.model_dump_json(indent=2).encode("utf-8")
        filename, media_type = f"{base}.report.json", "application/json"
    return Response(
        content=body,
        media_type=media_type,
        headers={"Content-Disposition": content_disposition(filename)},
    )
```

- **Deleted run:** if the run disappears mid-stream, it sends `event: deleted` with `data: {}` and ends.

```python
"""Run progress over server-sent events (spec §7.1). Each stream reads the run's progress every
api.progress_poll_s and sends an event when it changes, until the run reaches a terminal
state. GET /runs/{run_id}/progress is the polling fallback."""

import asyncio
import logging
import uuid
from collections.abc import AsyncIterator

from fastapi import APIRouter
from fastapi.responses import StreamingResponse
from sqlalchemy.exc import InterfaceError, OperationalError

from coglossa import service
from coglossa.schema import TERMINAL_STATES, RunProgress
from coglossa.store.db import error_reason
from coglossa.store.runs import NotFoundError
from coglossa_api.context import ApiContext, Ctx

log = logging.getLogger("coglossa.api")
router = APIRouter(tags=["runs"])
HEARTBEAT_S = 15.0  # comment lines keep proxies from closing a quiet stream


def _event(progress: RunProgress) -> str:
    return f"event: progress\ndata: {progress.model_dump_json()}\n\n"


async def _stream(ctx: ApiContext, run_id: uuid.UUID, first: RunProgress) -> AsyncIterator[str]:
    yield "retry: 3000\n\n"
    yield _event(first)
    last, quiet = first, 0.0
    poll = ctx.cfg.api.progress_poll_s
    while last.state not in TERMINAL_STATES:
        await asyncio.sleep(poll)
        try:
            current = await service.run_progress(ctx.db, run_id)
        except NotFoundError:
            yield "event: deleted\ndata: {}\n\n"
            return
        except (OperationalError, InterfaceError) as e:
            log.warning("progress stream ended: %s", error_reason(e), extra={"run_id": str(run_id)})
            return  # the browser reconnects after `retry`
        if current != last:
            yield _event(current)
            last, quiet = current, 0.0
        else:
            quiet += poll
            if quiet >= HEARTBEAT_S:
                yield ": keep-alive\n\n"
                quiet = 0.0


@router.get(
    "/runs/{run_id}/events",
    response_class=StreamingResponse,
    responses={200: {"content": {"text/event-stream": {}}}},
)
async def run_events(run_id: uuid.UUID, ctx: Ctx) -> StreamingResponse:
    """Server-sent events: `progress` (a RunProgress) whenever it changes; `deleted` if the
    run is deleted. The stream ends after a terminal state."""
    first = await service.run_progress(ctx.db, run_id)  # an unknown run is a plain 404
    return StreamingResponse(
        _stream(ctx, run_id, first),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )
```
